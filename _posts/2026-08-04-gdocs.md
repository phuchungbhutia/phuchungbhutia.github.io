## Part 1: Advanced Text Cleaning in Google Docs Using Regex

Whether you are editing a draft, cleaning up copied text from Wikipedia or research papers, or removing formatting tags, manually deleting citation brackets like `[1]`, `[2]`, or `[citation needed]` is tedious.

Google Docs features built-in Regular Expression support in its **Find and Replace** tool (`Ctrl + H` or `Cmd + H`).

### Understanding Greedy vs. Lazy Matching

When using regex in Google Docs, the single most common mistake is using a **greedy search** instead of a **lazy search**.

#### The Problem: Greedy Search (`\[.*\]`)
* **Regex Pattern:** `\[.*\]`
* **Behavior:** The `*` quantifier is *greedy*. It matches as much text as possible between the **first** opening bracket `[` and the **very last** closing bracket `]` in a paragraph.
* **Example Text:** `The quick brown fox [1] jumped over the lazy dog [2].`
* **Greedy Result:** It removes `[1] jumped over the lazy dog [2]`, accidentally destroying valid text!

#### The Solution: Lazy Search (`\[.*?\]` or Negated Sets)

To fix this, you have two options:

1. **Lazy Match (`\[.*?\]`):**
   * The `?` tells the quantifier `*` to stop at the **first** closing bracket `]` it encounters.
   * **Result:** Properly removes `[1]` and `[2]` while leaving the text between them intact.

2. **Negated Character Set (`\[[^\]]*\]`):**
   * This matches `[`, followed by any characters that are *not* a closing bracket (`[^\]]*`), followed by `]`.
   * **Result:** Extremely robust, especially in long documents.

---

### Step-by-Step: Removing Brackets in Google Docs

1. Open your document in Google Docs.
2. Press **`Ctrl + H`** (Windows/Linux) or **`Cmd + H`** (Mac) to open **Find and Replace**.
3. Check the box for **Use regular expressions**.
4. In the **Find** box, enter:
   ```regex
   \[.*?\]
   ```
5. Leave the **Replace with** box completely empty.
6. Click **Replace all**.

---

### Combining Regex to Remove Brackets AND Specific Characters

What if you want to clean bracketed citations *and* remove specific unwanted characters (like stray punctuation, pipe characters, or exclamation marks) in a single pass?

You can use the **OR operator (`|`)** in regex.

#### Example 1: Remove Brackets and Commas
```regex
\[.*?\]|,
```

#### Example 2: Remove Brackets and Specific Letters (e.g., 'x' and 'y')
```regex
\[.*?\]|[xy]
```

#### Example 3: Remove Brackets, Hashtags, and Exclamation Marks
```regex
\[.*?\]|[#!]
```

By leveraging regex, you can transform hours of manual text editing into a single click.

## Part 2: Dynamic Headers in Google Docs Using Google Apps Script

A common request among technical writers, legal professionals, and academic researchers is the ability to automatically sync document headers or footers with the document's main title or `Heading 1` text. 

While tools like Microsoft Word offer field codes (such as `STYLEREF`), Google Docs does not natively support dynamic header fields. However, you can easily add this functionality using **Google Apps Script**.

---

### Step-by-Step: Automating Headers with Google Apps Script

#### 1. Open the Script Editor
In your Google Doc, navigate to **Extensions > Apps Script**.

#### 2. Paste the Script Code
Delete any existing placeholder code in the editor and paste the following snippet:

```javascript
/**
 * Automatically creates a custom menu in Google Docs upon opening.
 */
function onOpen() {
  var ui = DocumentApp.getUi();
  ui.createMenu('Custom Tools')
      .addItem('Sync Header to Heading 1', 'updateHeaderWithHeading1')
      .addItem('Sync Footer to Heading 1', 'updateFooterWithHeading1')
      .addToUi();
}

/**
 * Searches the document for the first Heading 1 and updates the Header.
 */
function updateHeaderWithHeading1() {
  var doc = DocumentApp.getActiveDocument();
  var body = doc.getBody();
  var paragraphs = body.getParagraphs();
  var headingText = "";

  for (var i = 0; i < paragraphs.length; i++) {
    if (paragraphs[i].getHeading() === DocumentApp.ParagraphHeading.HEADING1) {
      headingText = paragraphs[i].getText();
      break; 
    }
  }

  if (headingText !== "") {
    var section = doc.getHeader() || doc.addHeader();
    section.clear();
    section.insertParagraph(0, headingText);
    DocumentApp.getUi().alert('Header successfully updated to: "' + headingText + '"');
  } else {
    DocumentApp.getUi().alert('No Heading 1 found in document.');
  }
}

/**
 * Searches the document for the first Heading 1 and updates the Footer.
 */
function updateFooterWithHeading1() {
  var doc = DocumentApp.getActiveDocument();
  var body = doc.getBody();
  var paragraphs = body.getParagraphs();
  var headingText = "";

  for (var i = 0; i < paragraphs.length; i++) {
    if (paragraphs[i].getHeading() === DocumentApp.ParagraphHeading.HEADING1) {
      headingText = paragraphs[i].getText();
      break; 
    }
  }

  if (headingText !== "") {
    var section = doc.getFooter() || doc.addFooter();
    section.clear();
    section.insertParagraph(0, headingText);
    DocumentApp.getUi().alert('Footer successfully updated to: "' + headingText + '"');
  } else {
    DocumentApp.getUi().alert('No Heading 1 found in document.');
  }
}
```

#### 3. Save and Reload
1. Click the **Save** icon (diskette) at the top of the Apps Script editor.
2. Return to your Google Doc tab and **refresh the browser page**.

#### 4. Run the Script
1. After refreshing, look at the top menu bar—you will see a new menu item called **Custom Tools**.
2. Click **Custom Tools > Sync Header to Heading 1** (or **Sync Footer to Heading 1**).
3. Grant authorization if Google Docs prompts you for permissions.

The script will instantly locate your first `Heading 1` in the document body and insert it cleanly into your header or footer area.
