Python for DevOps and Automation: Complete Beginner to Advanced Guide#

Python has become the language of choice for automation, cloud engineering, DevOps, data processing, cybersecurity, artificial intelligence, and backend development.

Its clean syntax, extensive standard library, and rich ecosystem make it one of the most productive programming languages available.

Whether you want to automate repetitive tasks, build APIs, manage cloud infrastructure, analyze logs, or deploy applications, Python is an essential skill.

This guide takes you from absolute beginner to building production-ready automation projects.

Why Learn Python?#

Python is used by companies of all sizes for automation and software development.

Common uses include:

  • System administration
  • Cloud automation
  • Web applications
  • REST APIs
  • Machine learning
  • AI applications
  • Data analysis
  • Cybersecurity
  • Monitoring
  • DevOps scripting

Python is beginner-friendly while still being powerful enough for enterprise software.

Installing Python#

Windows#

Download the latest Python installer.

During installation, enable:

Add Python to PATH

Verify installation:

python --version

or

python3 --version

Your First Program#

print("Hello, World!")

Save as:

hello.py

Run:

python hello.py

Variables#

Variables store information.

name = "Alice"

age = 25

salary = 65000

Python automatically determines the data type.

Data Types#

name = "John"

age = 30

height = 5.9

is_admin = False

Common types:

Type Example
str “Python”

bool True

User Input#

name = input("Enter your name: ")

print(name)

Convert numbers

age = int(input())

Strings#

language = "Python"

Length

len(language)

Uppercase

language.upper()

Lowercase

language.lower()

Replace

language.replace("Py", "My")

Lists#

fruits = ["Apple", "Banana", "Orange"]

Access

fruits[0]

Append

fruits.append("Mango")

Remove

fruits.remove("Banana")

Loop

for fruit in fruits:
    print(fruit)

Tuples#

Immutable collections.

point = (10, 20)

Dictionaries#

student = {
    "name": "John",
    "age": 20,
    "marks": 88
}

Access

student["name"]

Add

student["city"] = "Delhi"

Sets#

Unique values.

numbers = {1,2,3,3,4}

print(numbers)

Output

{1,2,3,4}

Conditional Statements#

age = 18

if age >= 18:
    print("Adult")
else:
    print("Minor")

Loops#

For loop

for i in range(5):
    print(i)

While loop

count = 0

while count < 5:
    print(count)
    count += 1

Functions#

def greet(name):
    return f"Hello {name}"

print(greet("Alice"))

Lambda Functions#

square = lambda x: x*x

print(square(5))

Modules#

import math

print(math.sqrt(25))

Import specific function

from math import factorial

Virtual Environments#

Create

python -m venv venv

Activate

Windows

venv\Scripts\activate

Linux

source venv/bin/activate

Deactivate

deactivate

Always use virtual environments for projects.

Package Management#

Install package

pip install requests

Upgrade

pip install --upgrade requests

Export dependencies

pip freeze > requirements.txt

Install later

pip install -r requirements.txt

File Handling#

Read

with open("notes.txt") as file:
    print(file.read())

Write

with open("hello.txt","w") as file:
    file.write("Python")

Append

with open("hello.txt","a") as file:
    file.write("\nDevOps")

Error Handling#

try:
    number = int(input())
except ValueError:
    print("Invalid number")
finally:
    print("Finished")

Object-Oriented Programming#

class Employee:

    def __init__(self,name):
        self.name = name

    def display(self):
        print(self.name)

emp = Employee("Alice")

emp.display()

Working with JSON#

import json

data = {
    "name":"Alice",
    "age":30
}

text = json.dumps(data)

print(text)

Load JSON

obj = json.loads(text)

Making API Requests#

Install

pip install requests

Example

import requests

response = requests.get("https://api.github.com")

print(response.status_code)

print(response.json())

Logging#

import logging

logging.basicConfig(level=logging.INFO)

logging.info("Application Started")

Avoid using print() for production applications.

Automation Example#

Rename files

import os

for filename in os.listdir():

    if filename.endswith(".txt"):

        os.rename(filename,
                  filename.replace(".txt",".md"))

Working with CSV#

import csv

with open("employees.csv") as file:

    reader = csv.reader(file)

    for row in reader:
        print(row)

Flask#

Install

pip install flask

Application

from flask import Flask

app = Flask(__name__)

@app.route("/")

def home():
    return "Hello World"

app.run()

Visit

http://localhost:5000

FastAPI#

Install

pip install fastapi uvicorn

Example

from fastapi import FastAPI

app = FastAPI()

@app.get("/")

def home():
    return {"message":"Hello"}

Run

uvicorn main:app --reload

FastAPI is an excellent choice for modern APIs.

Unit Testing#

import unittest

class TestMath(unittest.TestCase):

    def test_add(self):

        self.assertEqual(2+2,4)

if __name__ == "__main__":

    unittest.main()

Best Practices#

  • Follow PEP 8 coding standards.
  • Use meaningful variable names.
  • Write reusable functions.
  • Handle exceptions gracefully.
  • Use logging instead of print statements.
  • Store secrets in environment variables.
  • Write unit tests.
  • Use virtual environments.
  • Document your code.
  • Keep functions small and focused.
