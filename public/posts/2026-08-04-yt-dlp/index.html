Command-line utilities often outperform bloated desktop applications when it comes to speed, flexibility, and reliability. For downloading online video and audio, yt-dlp stands out as the community gold standard—a actively maintained fork of the classic youtube-dl project.

Whether you are archiving full concert playlists, podcasts, or music collections, setting up yt-dlp alongside ffmpeg ensures seamless extraction into high-quality MP3s across Windows, Linux Mint, and Arch-based distributions like Manjaro.

1. Installation Guide Across Operating Systems#

Because streaming platforms continually update their backends, installing yt-dlp from a source that allows easy updates is critical.

Windows Setup#

  1. Download the Executable:

    • Visit the official yt-dlp GitHub Releases page.
    • Download yt-dlp.exe.
    • Create a dedicated directory (for example, C:\\yt-dlp) and place yt-dlp.exe inside it.

  2. Install FFmpeg (Crucial for MP3 Conversion):

    • Download a static build from Gyan.dev FFmpeg Builds.
    • Extract the ZIP archive and copy ffmpeg.exe and ffprobe.exe from the bin folder into your C:\\yt-dlp folder.

  3. Add to System Path:

    • Open the Start Menu, search for Environment Variables, and select Edit the system environment variables.
    • Click Environment Variables…
    • Under User variables, select Path and click Edit.
    • Add C:\\yt-dlp and save. You can now run yt-dlp from any Command Prompt or PowerShell window.

Linux Mint (and Ubuntu / Debian Derivatives)#

Official distribution repositories can lag behind active yt-dlp development. Using a Personal Package Archive (PPA) ensures access to recent releases.

# Add the maintained PPA
sudo add-apt-repository ppa:tomtomtom/yt-dlp

# Update package lists and install yt-dlp along with ffmpeg
sudo apt update
sudo apt install yt-dlp ffmpeg

Manjaro (and Arch Linux)#

Arch-based systems keep repositories up to date. You can install yt-dlp directly via pacman or grab the AUR package.

# Install via official repositories
sudo pacman -Syu yt-dlp ffmpeg

2. Downloading Full Playlists as MP3s#

To pull down an entire playlist, extract the audio track, convert it to maximum-quality MP3, and embed the original video cover art into the file tags, use the unified command below.

The Standard Command#

yt-dlp -x --audio-format mp3 --audio-quality 0 --embed-thumbnail --yes-playlist -o "%(playlist_index)s - %(title)s.%(ext)s" "PLAYLIST_URL"

3. Practical Example and Flag Breakdown#

Here is a breakdown of what happens when processing a playlist containing 20 tracks:

Example Execution#

yt-dlp -x --audio-format mp3 --audio-quality 0 --embed-thumbnail -o "%(playlist_index)s - %(title)s.%(ext)s" "[https://www.youtube.com/playlist?list=PL4fGSI1pDJn6O1LS0XSdF3RyO0Aq_E-mO](https://www.youtube.com/playlist?list=PL4fGSI1pDJn6O1LS0XSdF3RyO0Aq_E-mO)"

Flag Reference#

ParameterFunctionDescription
-xExtract AudioDrops the video stream and retains only the raw audio stream.
--audio-format mp3TranscodeUses ffmpeg to re-encode the stream into the target .mp3 format.
--audio-quality 0Bitrate SettingTargets VBR 0 (~220–260 kbps) or maximum available quality.
--embed-thumbnailMetadata TaggingEmbeds the video thumbnail directly into the MP3’s ID3 artwork field.
--yes-playlistStream HandlingExplicitly forces full playlist parsing even if a single video URL is provided within a list.
-o "%(playlist_index)s - %(title)s.%(ext)s"Output FormattingNames files cleanly in numerical order based on playlist index (e.g., 01 - Track Title.mp3).

4. Automation and Maintenance Tips#

  1. Keep yt-dlp Updated: Whenever a download fails or drops speed, update the binary immediately:
yt-dlp -U
  1. Windows Quick-Run Script (Batch File): Create a desktop file named dl_mp3.bat with the following contents:
@echo off
set /p url="Enter YouTube/Playlist URL: "
yt-dlp -x --audio-format mp3 --audio-quality 0 --embed-thumbnail -o "%%(playlist_index)s - %%(title)s.%%(ext)s" %url%
pause
