# Git & GitHub: Complete Beginner to Advanced Guide for Modern Development

Git is the most widely used version control system in the world. Whether you're building a personal website, contributing to open source, or deploying applications to the cloud, Git is an essential skill.

Git keeps track of every change you make, while GitHub provides a platform to store repositories, collaborate with others, automate workflows, and publish projects.

In this guide, you'll learn Git from scratch and build habits used by professional software teams.

# What is Version Control?

Version control is a system that records changes made to files over time.

Benefits:

- Recover previous versions
- Track who changed what
- Collaborate safely
- Experiment without losing work
- Maintain project history

Without version control:

```
project-final.zip
project-final2.zip
project-final-final.zip
project-final-really-final.zip
```

With Git:

```
Commit History

Initial Project
↓

Added Login

↓

Fixed Bug

↓

Released Version 1.0
```

---

# What is Git?

Git is a distributed version control system created by Linus Torvalds in 2005.

Features:

- Fast
- Lightweight
- Offline support
- Distributed
- Reliable
- Open Source

Git stores snapshots instead of simply saving differences.

---

# What is GitHub?

GitHub is a cloud platform built around Git.

GitHub provides:

- Remote repositories
- Collaboration
- Pull Requests
- Issues
- GitHub Actions
- GitHub Pages
- Wikis
- Releases
- Discussions
- Security scanning

# Git vs GitHub

| Git | GitHub |
|------|---------|
| Version control software | Cloud hosting platform |
| Works locally | Works online |
| Tracks changes | Stores repositories |
| Command line | Web interface |
| Open source | Free & Paid plans |

# Configure Git

Tell Git who you are.

```bash

```

```bash

```

Check configuration

```bash

```

# Your First Repository

Create a folder.

```bash
mkdir hello-git
```

Enter it.

```bash
cd hello-git
```

Initialize Git.

```bash
git init
```

Git creates a hidden folder.

```
.git
```

This contains all repository history.

---

# First Commit

Create a file.

```bash
echo "# Hello Git" > README.md
```

Check status.

```bash
git status
```

Stage the file.

```bash
git add README.md
```

Commit.

```bash
git commit -m "Initial commit"
```

Congratulations!

You have created your first Git history.

# Branches

A branch lets you work independently.

Create

```bash
git branch feature-login
```

Switch

```bash
git checkout feature-login
```

Modern command

```bash
git switch feature-login
```

Create and switch

```bash
git switch -c feature-login
```

List branches

```bash
git branch
```

---

# Merge Branches

Return to main

```bash
git switch main
```

Merge

```bash
git merge feature-login
```

Delete merged branch

```bash
git branch -d feature-login
```

---

# Merge Conflicts

Sometimes two people edit the same lines.

Git marks conflicts like this:

```text
<<<<<<< HEAD

Current Version

=======

Incoming Version

>>>>>>> feature-login
```

Resolve manually.

Then:

```bash
git add .
git commit
```

# Remote Repository

Connect GitHub.

```bash
git remote add origin https://github.com/user/project.git
```

View remotes

```bash
git remote -v
```

Push

```bash
git push -u origin main
```

Future pushes

```bash
git push
```

# Pull Latest Changes

```bash
git pull
```

Fetch only

```bash
git fetch
```

Difference

| Fetch | Pull |
|--------|------|
| Downloads changes | Downloads + merges |

# Undo Mistakes

Restore file

```bash
git restore file.txt
```

Undo staging

```bash
git restore --staged file.txt
```

Revert commit

```bash
git revert COMMIT_ID
```

# Git Ignore

Create

```
.gitignore
```

Example

```text
node_modules/
*.log
.env
__pycache__/
*.pyc
dist/
```

Never commit:

- Passwords
- API Keys
- Secrets
- Build folders

# GitHub Actions

Automate workflows.

Example

```
Push Code

↓

Run Tests

↓

Build Docker Image

↓

Deploy Website
```

Simple workflow

```yaml
name: Build

on: push

jobs:
  test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Say Hello
        run: echo "Hello GitHub Actions"
```
