Git & GitHub: Complete Beginner to Advanced Guide for Modern Development#

Git is the most widely used version control system in the world. Whether you’re building a personal website, contributing to open source, or deploying applications to the cloud, Git is an essential skill.

Git keeps track of every change you make, while GitHub provides a platform to store repositories, collaborate with others, automate workflows, and publish projects.

In this guide, you’ll learn Git from scratch and build habits used by professional software teams.

What is Version Control?#

Version control is a system that records changes made to files over time.

Benefits:

  • Recover previous versions
  • Track who changed what
  • Collaborate safely
  • Experiment without losing work
  • Maintain project history

Without version control:

project-final.zip
project-final2.zip
project-final-final.zip
project-final-really-final.zip

With Git:

Commit History

Initial Project
↓

Added Login

↓

Fixed Bug

↓

Released Version 1.0

What is Git?#

Git is a distributed version control system created by Linus Torvalds in 2005.

Features:

  • Fast
  • Lightweight
  • Offline support
  • Distributed
  • Reliable
  • Open Source

Git stores snapshots instead of simply saving differences.

What is GitHub?#

GitHub is a cloud platform built around Git.

GitHub provides:

  • Remote repositories
  • Collaboration
  • Pull Requests
  • Issues
  • GitHub Actions
  • GitHub Pages
  • Wikis
  • Releases
  • Discussions
  • Security scanning

Installing Git#

Ubuntu

sudo apt install git

Windows

Download Git for Windows and install with default options.

Verify installation

git --version

Configure Git#

Tell Git who you are.

git config --global user.name "Your Name"

git config --global user.email "you@example.com"

Check configuration

git config --list

Your First Repository#

Create a folder.

mkdir hello-git

Enter it.

cd hello-git

Initialize Git.

git init

Git creates a hidden folder.

.git

This contains all repository history.

First Commit#

Create a file.

echo "# Hello Git" > README.md

Check status.

git status

Stage the file.

git add README.md

Commit.

git commit -m "Initial commit"

Congratulations!

You have created your first Git history.

Branches#

A branch lets you work independently.

Create

git branch feature-login

Switch

git checkout feature-login

Modern command

git switch feature-login

Create and switch

git switch -c feature-login

List branches

git branch

Merge Branches#

Return to main

git switch main

Merge

git merge feature-login

Delete merged branch

git branch -d feature-login

Merge Conflicts#

Sometimes two people edit the same lines.

Git marks conflicts like this:

<<<<<<< HEAD

Current Version

=======

Incoming Version

>>>>>>> feature-login

Resolve manually.

Then:

git add .
git commit

Remote Repository#

Connect GitHub.

git remote add origin https://github.com/user/project.git

View remotes

git remote -v

Push

git push -u origin main

Future pushes

git push

Clone Existing Repository#

git clone https://github.com/user/project.git

This downloads the entire history.

Pull Latest Changes#

git pull

Fetch only

git fetch

Difference

FetchPull
Downloads changesDownloads + merges

Undo Mistakes#

Restore file

git restore file.txt

Undo staging

git restore --staged file.txt

Revert commit

git revert COMMIT_ID
