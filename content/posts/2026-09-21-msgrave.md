# Technical Overview of Microsoft Activation Scripts

Microsoft Activation Scripts (MAS) is an open-source utility designed to manage the activation state of Windows and Microsoft Office products [[1]]. Hosted at massgrave.dev, the project provides a transparent, script-based alternative to proprietary activation tools. By leveraging native operating system capabilities, MAS supports multiple activation vectors tailored to different product versions and deployment scenarios [[2]].

## Core Activation Methodologies

MAS implements four primary activation mechanisms, each serving distinct technical requirements and product compatibilities.

- **HWID (Hardware ID)**: This method generates a permanent digital license tied to the device motherboard. It requires an initial internet connection to register the hardware hash with Microsoft servers, after which the activation persists across clean installations of Windows 10 and Windows 11 [[1]].
- **Ohook**: Designed specifically for Microsoft Office, Ohook provides permanent activation by modifying local hook mechanisms. This method operates entirely offline and does not require recurring network validation [[1]].
- **TSforge**: A newer activation vector supporting Windows, Extended Security Updates (ESU), and Office. It offers permanent activation, though certain implementations (such as the StaticCID method on build 26100 and above) may require brief internet access [[1]].
- **Online KMS**: This method emulates a Key Management Service server to activate Windows and Office for a 180-day period. MAS installs an automated renewal task that extends this period indefinitely, effectively providing lifetime activation as long as the system periodically connects to the network [[1]].

| Activation Type | Supported Product      | Activation Period        | Internet Required      |
| ---             | ---                    | ---                      | ---                    |
| HWID            | Windows 10 and 11      | Permanent                | Yes (Initial only)     |
| Ohook           | Microsoft Office       | Permanent                | No                     |
| TSforge         | Windows, ESU, Office   | Permanent                | Conditional            |
| Online KMS      | Windows, Office        | 180 Days (Auto-renewing) | Yes (Periodic)         |

## Operational Mechanics and Deployment

The project distributes its functionality primarily through lightweight batch and PowerShell scripts, avoiding the need for compiled executables that often trigger heuristic antivirus alerts [[2]]. Users can deploy MAS via two principal pathways.

### PowerShell Execution (Recommended)
The most efficient deployment method utilizes the `Invoke-RestMethod` (`irm`) and `Invoke-Expression` (`iex`) cmdlets. This approach fetches the latest script directly from the official repository and executes it in memory without writing to disk [[3]].

```powershell
irm https://get.activated.win | iex
```

For environments where standard DNS resolution is intercepted or blocked by an Internet Service Provider, MAS provides a DNS-over-HTTPS (DoH) bypass utilizing Cloudflare resolvers [[1]].

```powershell
iex (curl.exe -s --doh-url https://1.1.1.1/dns-query https://get.activated.win | Out-String)
```

### Traditional Offline Deployment
For air-gapped systems or restrictive security policies, MAS offers a standalone `MAS_AIO.cmd` file [[1]]. Users download the script or its archived ZIP equivalent, verify its integrity, and execute it locally. The script presents a text-based menu where numeric selection triggers the desired activation routine.

## Security and Integrity Considerations

The open-source nature of MAS is its primary security asset. Every line of code is publicly auditable on GitHub, ensuring no hidden payloads or telemetry are embedded within the scripts [[2]]. However, this transparency also necessitates strict operational discipline from the end user.

- **Source Verification**: The official PowerShell command must be copied exactly as published. Third-party websites frequently alter the URL to point to malicious scripts disguised as legitimate activation tools [[3]].
- **Antivirus Heuristics**: While the scripts themselves are benign, the behavior of modifying system licensing tokens can trigger false positives in overzealous endpoint protection platforms. The project maintains a low detection rate by avoiding obfuscated code [[2]].
- **Network Mitigation**: In regions or networks where massgrave.dev or its redirectors are blocked, enabling DNS-over-HTTPS in the browser or utilizing a trusted VPN is required to access the official documentation and script endpoints [[1]].

MAS represents a mature, community-driven solution for software licensing management. Its reliance on native scripting languages and publicly documented methods provides system administrators and advanced users with a verifiable and controllable activation workflow.
