# The Ultimate Linux Mint Power-User Guide: From Memory Tuning to a Bazzite-Grade Gaming Rig

Linux Mint Cinnamon is renowned for its stability and ease of use. However, out-of-the-box configurations often leave significant performance potential untapped on modern hardware, such as 12th Gen Intel hybrid CPUs with dedicated Nvidia graphics and NVMe storage. This guide details the transformation of a standard Linux Mint installation into a finely tuned, gaming-ready daily driver by implementing tiered memory architectures, clean storage management, and immutable-style gaming toolchains.

## Part 1: Tiered Memory Tuning — Taming Swapping with zram and NVMe

### Why the Default Swap Strategy Fails Modern Workloads

Standard Linux installations typically configure a small swap file (often 2 GB) with a default `swappiness` value of 60. Under heavy multitasking or gaming loads, the kernel begins writing uncompressed memory pages to physical disk. Even on Gen4 NVMe drives, this introduces micro-stutters and I/O wait latency.

The solution is not to disable swap, but to implement `zram`: a compressed block device residing in RAM. This creates a two-tier strategy:

1.  **Tier 1 (Priority 100):** `zram` compressed with `zstd`. It intercepts memory pressure immediately, compressing inactive pages at multi-gigabyte-per-second speeds.
2.  **Tier 2 (Priority 10):** An expanded 8 GB `/swapfile` on NVMe. This serves as emergency overflow to prevent the Out-Of-Memory (OOM) killer from triggering during edge-case spikes.

### Implementation

#### 1. Deploy and Configure zram-tools

Install the package and configure it to use half of the system RAM with `zstd` compression:

```bash
sudo apt update && sudo apt install -y zram-tools
```

Edit `/etc/default/zramswap` to set the algorithm, size, and priority:

```text
ALGO=zstd
PERCENT=50
PRIORITY=100
```

Restart the service to apply changes:

```bash
sudo systemctl restart zramswap.service
```

#### 2. Re-allocate the On-Disk Swap File

Expand the disk swap file to 8 GB and assign it a lower priority than `zram`:

```bash
sudo swapoff -a
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo sed -i '/\/swapfile/d' /etc/fstab
echo '/swapfile none swap sw,pri=10 0 0' | sudo tee -a /etc/fstab
sudo swapon -a
```

#### 3. Optimize Kernel Virtual Memory Parameters

Create `/etc/sysctl.d/99-zram-tuning.conf` to encourage aggressive compression of idle memory rather than evicting filesystem caches:

```text
vm.swappiness=150
vm.vfs_cache_pressure=100
vm.page-cluster=0
vm.dirty_background_ratio=5
vm.dirty_ratio=10
```

Load the new parameters:

```bash
sudo sysctl --system
```

Verify the setup with `swapon --show`. You should see `/dev/zram0` with a priority of 100 and `/swapfile` with a priority of 10.

## Part 2: Clean Storage Architecture — Preserving Your Linux Home Across Disks

Offloading bulky folders like Downloads and Videos to a secondary partition is common, but mounting an entire non-Linux filesystem (NTFS/exFAT) over `/home` breaks POSIX permissions, SSH keys, and desktop configs. The correct approach uses targeted symbolic links pointing to a persistent system mount.

### Configuring the Mount via Disks

Use the `gnome-disks` utility to ensure the secondary partition mounts at boot:
1.  Select the target partition and choose **Edit Mount Options**.
2.  Uncheck **User Session Defaults**.
3.  Set **Identify As** to `UUID=...` for persistence.
4.  Set the **Mount Point** to `/mnt/New`.
5.  Ensure options include `nosuid,nodev,nofail` and, for NTFS, `windows_names,uid=1000,gid=1000,umask=022`.

### Automating Symlinks and Updating XDG User Dirs

Run the following script to migrate user directories to the secondary mount while preserving local configuration files:

```bash
sudo mkdir -p /mnt/New && \
sudo chown -R $USER:$USER /mnt/New 2>/dev/null; \
mkdir -p /mnt/New/Users/phuch/{Desktop,Documents,Downloads,Music,Pictures,Videos} && \
cd ~ && \
rmdir Desktop Documents Downloads Music Pictures Videos 2>/dev/null; \
ln -sfn /mnt/New/Users/phuch/Desktop ~/Desktop && \
ln -sfn /mnt/New/Users/phuch/Documents ~/Documents && \
ln -sfn /mnt/New/Users/phuch/Downloads ~/Downloads && \
ln -sfn /mnt/New/Users/phuch/Music ~/Music && \
ln -sfn /mnt/New/Users/phuch/Pictures ~/Pictures && \
ln -sfn /mnt/New/Users/phuch/Videos ~/Videos && \
xdg-user-dirs-update --set DESKTOP "$HOME/Desktop" && \
ls -ld ~/Desktop ~/Documents ~/Downloads ~/Music ~/Pictures ~/Videos
```

## Part 3: Linux Mint vs. Bazzite — Building an Immutable-Style Gaming Rig

Bazzite OS, built on Fedora Atomic, offers an immutable root, turnkey gaming stack, and containerized applications. While Linux Mint is traditional, it can be configured to match Bazzite’s capabilities.

### 1. Raise Kernel Limits for Heavy Games

Modern anti-cheat and Proton games often exceed default memory map limits. Create `/etc/sysctl.d/80-game-tuning.conf`:

```text
fs.file-max=524288
vm.max_map_count=2147483642
```

Apply with `sudo sysctl --system`.

### 2. Install Game Engine Tools and Launchers

Enable 32-bit architecture and install essential gaming libraries and launchers:

```bash
sudo dpkg --add-architecture i386 && sudo apt update
sudo apt install -y gamemode mangohud vulkan-tools libvulkan1 libvulkan1:i386 steam-installer lutris
```

Add Flathub and install Heroic Games Launcher and ProtonUp-Qt:

```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install -y flathub net.davidotek.pupgui2 com.heroicgameslauncher.hgl
```

### 3. Container Tooling with Distrobox

Install `podman` and `distrobox` to run software from other distributions, such as Arch Linux AUR packages:

```bash
sudo apt install -y podman distrobox
distrobox create --name arch-box --image archlinux:latest
distrobox enter arch-box
```

### 4. Android Emulation with Waydroid

Since Mint Cinnamon runs on X11, Waydroid requires a Weston compositor bridge:

```bash
curl -s https://repo.waydro.id | sudo bash
sudo apt update && sudo apt install -y waydroid weston
sudo waydroid init -s GAPPS
sudo systemctl enable --now waydroid-container
```

Launch the Android UI within a Weston window:

```bash
weston --width=1080 --height=1920 &
WAYLAND_DISPLAY=wayland-1 waydroid show-full-ui
```

### 5. Optimizing Dedicated Nvidia Graphics

For dual-GPU systems, configure Steam Launch Options to offload rendering to the Nvidia GPU with GameMode optimizations:

```text
gamemoderun __NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia %command%
```

To include real-time metrics, prepend `mangohud`:

```text
mangohud gamemoderun __NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia %command%
```

## Part 4: Keeping Tabs on Throughput — Network Monitoring in Cinnamon

### The Cinnamon Panel Applet Method

1.  Right-click the panel and select **Applets**.
2.  Navigate to the **Download** tab and search for **Net Speed (Text Only)**.
3.  Install and add it to the panel.
4.  Configure the applet to monitor your active Wi-Fi or Ethernet interface.

### The Power-User CLI Method

Install `nload` and `speedtest-cli` for terminal-based monitoring:

```bash
sudo apt install -y nload speedtest-cli
```

*   `nload`: Provides real-time graphical bandwidth visualization.
*   `speedtest-cli --simple`: Verifies connection bandwidth and ping from the shell.

## Conclusion

By replacing traditional swap with a hybrid `zram` and NVMe tiered memory layout, isolating bulk data on secondary storage via symlinks, and integrating Bazzite-inspired gaming and container toolchains, Linux Mint transforms into a resilient, high-performance workstation. This approach retains the stability of an LTS distribution while delivering the advanced capabilities required for modern gaming and development.
