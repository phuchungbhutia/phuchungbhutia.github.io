Most modern browsers ship with proprietary sync engines that lock your data into a single vendor ecosystem. If you switch between Chrome at work, Firefox on your laptop, and Brave on your desktop, keeping bookmarks consistent usually means exporting HTML files manually or giving up privacy to third-party cloud providers.

**Floccus Bookmarks Sync** solves this dilemma. It is a free, open-source browser extension and mobile client that synchronizes bookmarks across multiple browsers and platforms using a server or cloud drive you already control.

---

## 🔎 Key Features

* **Cross-Browser Compatibility:** Sync your links seamlessly across Chrome, Firefox, Microsoft Edge, Brave, Opera, and Vivaldi. *(Note: Safari desktop is not currently supported due to WebExtension API restrictions).*
* **Flexible Storage Backends:** Floccus does not operate central data servers. Instead, you connect it to your preferred storage provider:
  * Self-hosted options: Nextcloud Bookmarks, Linkwarden, KaraKeep, native Git repositories, or any WebDAV endpoint.
  * Consumer cloud drives: Google Drive, Dropbox, or OneDrive.
* **Client-Side Encryption:** Includes optional end-to-end encryption (E2EE) for WebDAV and Google Drive backends, keeping your bookmark hierarchies private before data leaves your device.
* **Dedicated Mobile Companions:** Access, organize, and launch your synced URLs on iOS and Android.

## ⚙️ Step-by-Step Setup Guide

Setting up Floccus requires installing the extension on your primary browser, exporting/mapping to your target file, and then pointing secondary browsers to the same sync target.

### Step 1: Install the Extension
Add Floccus to your desktop browser via the Chrome Web Store or Firefox Add-ons directory using the links provided above.

### Step 2: Configure Your Sync Target
1. Open your browser's extension panel and open the **Floccus** settings menu.
2. Select **+ New Account**.
3. Choose your backend of choice (e.g., *WebDAV*, *Nextcloud*, or *Google Drive*).

```text
+-------------------------------------------------------------+
| Select Sync Method                                          |
+-------------------------------------------------------------+
| [ ] Nextcloud Bookmarks                                     |
| [X] WebDAV (Recommended for self-hosters and Koofr/Nextcloud)|
| [ ] Google Drive                                            |
| [ ] Git Repository                                          |
+-------------------------------------------------------------+

```

### Step 3: Map Folders and Secure Data

* **Local Folder:** Select which local folder to synchronize (e.g., `Bookmarks Bar` or a specific dedicated subfolder).
* **Remote File Path:** Provide the destination path on your storage hub (for example, `/bookmarks.xbel`).
* **Encryption (Optional but Recommended):** Set a client-side passphrase. Remember this phrase, as every connected browser instance will require it to decrypt the file.

### ⚠️ Crucial Step: Disable Native Browser Sync

> **Important:** Disable your browser's built-in bookmark sync (such as Google Chrome Sync or Firefox Sync) for the folders managed by Floccus. Leaving both synchronizers active simultaneously creates race conditions, infinite sync loops, and massive duplicate bookmark folders.

## 📱 Understanding Mobile Limitations

Because of sandboxing policies on Android and iOS, companion applications cannot inject bookmarks directly into third-party mobile browsers like stock mobile Chrome or iOS Safari.

Instead, the Floccus mobile client functions as a standalone bookmark viewer:

* Browse, search, and manage your full folder tree on your phone.
* Tap any bookmark to open it in your default mobile browser.
* Share URLs from mobile apps directly into Floccus to save them back to your synchronized desktop collections.
