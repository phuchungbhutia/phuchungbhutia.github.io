# Building a PDF-to-DOCX Converter in Python: Troubleshooting Pip, Environments, and Document Bugs

Converting PDF files into editable `.docx` documents in Python is straightforward once your environment and script are set up properly. However, subtle pitfalls around `python -m pip`, virtual environments, and closed document handles can trip up a build. This guide covers how to install dependencies reliably and build a clean PDF-to-`.docx` converter using `pymupdf` and `python-docx`.

## Why python -m pip Matters

Running `pip install` directly can install packages into a different Python interpreter than the one executing your script. Using `python -m pip` guarantees `pip` runs inside the exact Python interpreter you invoke.

### Useful python -m pip Commands

```bash
# Check which Python and pip are active
which python
python -m pip --version

# Upgrade pip inside the active environment
python -m pip install --upgrade pip

# Install required libraries for PDF-to-DOCX conversion
python -m pip install pymupdf python-docx

# Verify installed package versions
python -m pip list
```

### Virtual Environment Best Practices

Activate the virtual environment first so packages stay isolated and reproducible. This prevents conflicts with system-wide Python installations and resolves PEP 668 restrictions.

```bash
# Create a virtual environment if one does not exist
python -m venv .venv

# Activate on Linux or macOS
source .venv/bin/activate

# Install dependencies into .venv
python -m pip install pymupdf python-docx
```

## Complete PDF-to-DOCX Converter Script

This script extracts non-table text blocks and vector tables in reading order using `pymupdf`. It strips standalone page folios, formats uppercase headers, and writes a structured `.docx` file with `python-docx`.

```python
import re
import sys
import argparse
import logging
from pathlib import Path
import pymupdf
from docx import Document
from docx.shared import Inches, Pt
from docx.enum.table import WD_TABLE_ALIGNMENT

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%H:%M:%S",
)
log = logging.getLogger("pdf2docx")


def _clean_cell(text: str | None) -> str:
    """Collapses line breaks and repeated spaces inside a table cell or block."""
    if not text:
        return ""
    return re.sub(r"\s+", " ", text).strip()


def _is_page_folio(text: str) -> bool:
    """Identifies standalone page numbers like '1', '-124-', or '127'."""
    return bool(re.fullmatch(r"-?\s*\d{1,3}\s*-?", text.strip()))


def convert_pdf_to_docx(
    pdf_path: Path,
    docx_path: Path,
    strip_folios: bool = True,
    page_breaks: bool = False,
) -> None:
    """Converts a PDF into a .docx document preserving blocks and detected tables."""
    doc = pymupdf.open(str(pdf_path))
    page_count = len(doc)
    word_doc = Document()

    # Configure A4 page margins (0.8 in on all sides)
    for section in word_doc.sections:
        section.page_width = Inches(8.27)
        section.page_height = Inches(11.69)
        section.left_margin = Inches(0.8)
        section.right_margin = Inches(0.8)
        section.top_margin = Inches(0.8)
        section.bottom_margin = Inches(0.8)

    normal_style = word_doc.styles["Normal"]
    normal_style.font.name = "Calibri"
    normal_style.font.size = Pt(10.5)

    for page_idx, page in enumerate(doc):
        tabs = page.find_tables()
        table_rects = [pymupdf.Rect(t.bbox) for t in tabs.tables]

        # Collect (y0, x0, kind, payload) items so text and tables stay in reading order
        elements: list[tuple[float, float, str, object]] = []

        # 1. Non-table text blocks
        for block in page.get_text("blocks"):
            x0, y0, x1, y1, raw_text, *_ = block
            rect = pymupdf.Rect(x0, y0, x1, y1)

            if any(rect.intersects(tr) for tr in table_rects):
                continue

            cleaned = _clean_cell(raw_text)
            if not cleaned:
                continue
            if strip_folios and _is_page_folio(cleaned):
                continue

            elements.append((y0, x0, "text", cleaned))

        # 2. Detected tables
        for tab in tabs.tables:
            extracted = tab.extract()
            if not extracted:
                continue
            cleaned_rows = [
                [_clean_cell(cell) for cell in row]
                for row in extracted
                if any(_clean_cell(c) for c in row)
            ]
            if cleaned_rows:
                elements.append((tab.bbox[1], tab.bbox[0], "table", cleaned_rows))

        elements.sort(key=lambda item: (round(item[0], 1), round(item[1], 1)))

        for _, _, kind, payload in elements:
            if kind == "text":
                text_str = str(payload)
                if len(text_str) <= 90 and text_str.isupper() and len(text_str.split()) >= 2:
                    word_doc.add_heading(text_str.title(), level=2)
                else:
                    p = word_doc.add_paragraph(text_str)
                    p.paragraph_format.space_after = Pt(6)

            elif kind == "table":
                rows_data = payload
                col_count = max(len(r) for r in rows_data)
                table = word_doc.add_table(rows=len(rows_data), cols=col_count)
                table.style = "Table Grid"
                table.alignment = WD_TABLE_ALIGNMENT.CENTER

                for r_idx, row_vals in enumerate(rows_data):
                    row_cells = table.rows[r_idx].cells
                    for c_idx in range(col_count):
                        val = row_vals[c_idx] if c_idx < len(row_vals) else ""
                        cell_obj = row_cells[c_idx]
                        cell_obj.text = val
                        for run in cell_obj.paragraphs[0].runs:
                            run.font.size = Pt(9.5)
                            if r_idx == 0:
                                run.bold = True

                word_doc.add_paragraph()

        if page_breaks and page_idx < page_count - 1:
            word_doc.add_page_break()

    docx_path.parent.mkdir(parents=True, exist_ok=True)
    word_doc.save(str(docx_path))
    doc.close()
    log.info("Saved DOCX to: %s (%d pages processed)", docx_path, page_count)


def main() -> None:
    parser = argparse.ArgumentParser(
        description="Convert a PDF file into a .docx Word document with table support."
    )
    parser.add_argument("input_pdf", help="Path to source .pdf file")
    parser.add_argument(
        "-o",
        "--output",
        help="Output .docx path (default: output/<pdf_name>.docx)",
    )
    parser.add_argument(
        "--keep-folios",
        action="store_true",
        help="Keep standalone page numbers in the output .docx",
    )
    parser.add_argument(
        "--page-breaks",
        action="store_true",
        help="Insert a hard Word page break after each PDF page",
    )
    args = parser.parse_args()

    pdf_path = Path(args.input_pdf)
    if not pdf_path.is_file():
        log.error("PDF file not found: %s", pdf_path)
        sys.exit(1)

    out_path = (
        Path(args.output)
        if args.output
        else Path("output") / f"{pdf_path.stem}.docx"
    )

    convert_pdf_to_docx(
        pdf_path=pdf_path,
        docx_path=out_path,
        strip_folios=not args.keep_folios,
        page_breaks=args.page_breaks,
    )


if __name__ == "__main__":
    main()
```

## Troubleshooting Common Errors and Pitfalls

### No Module Named pip or Externally Managed Environment
Creating and activating a project virtual environment first resolves this PEP 668 error. This ensures you have write permissions to the environment's site-packages directory.

* Create the environment: `python -m venv .venv`
* Activate it: `source .venv/bin/activate`
* Upgrade and install: `python -m pip install --upgrade pip pymupdf python-docx`

### ModuleNotFoundError for pymupdf or docx
This occurs when the package installs globally while `python` runs from a virtual environment. Always install using the exact interpreter you intend to run.

> **Note:** The import name for `python-docx` is `docx`, not `python_docx`.

### ValueError: Document Closed After doc.close()
Calling `len(doc)` or reading properties on a `pymupdf` document after `doc.close()` raises a `ValueError`. Store the page count in a variable before closing the document, then reference that variable in your final log statement.

### Informational Notice Regarding pymupdf_layout
PyMuPDF may print a layout notice on startup before the final log line. Treat this as an informational notice rather than a crash if the script successfully saves the `.docx` file.

### Scanned Image PDFs Produce Empty Text
Scanned PDFs produce empty `.docx` files because pages contain raster images rather than selectable text layers. Run OCR on the PDF first using a tool like `ocrmypdf` before executing the conversion script.

## Summary

* Use `python -m pip` to guarantee package installation in the active interpreter.
* Isolate dependencies using a project-level virtual environment like `.venv`.
* Extract `page_count` before calling `doc.close()` to avoid `ValueError`.
* Pre-process scanned PDFs with `ocrmypdf` to ensure text extraction works reliably.
