Managing virtual memory is essential for maintaining system stability and preventing out-of-memory crashes on Linux Mint. Swap space acts as a spillover pool for your physical RAM, allowing the system to offload inactive memory pages onto storage drives when hardware resources are fully saturated. Whether you are working with limited hardware or running memory-intensive workloads, mastering swap creation and kernel swappiness tuning ensures optimal desktop responsiveness.

---

## 1. Checking Active Swap Space

Before creating new virtual memory, verify whether your system currently has an active swap file or partition.

Open your terminal and run the following command to check active swap devices:

```bash
swapon --show

```

Alternatively, check total memory utilization using the standard free utility:

```bash
free -h

```

If the `swapon --show` command returns an empty list or `free -h` shows zero bytes for swap, your system currently has no swap space enabled.

---

## 2. Enabling Pre-configured Swap

If your system already has an existing swap file or swap partition set up in your system configuration files but it is currently turned off, you can activate it directly.

```bash
sudo swapon -a

```

Executing `swapon -a` scans your system files and turns on all listed swap devices in one step.

---

## 3. How to Create and Enable a New Swap File

If your machine does not have a swap file, you can manually generate one, set file permissions, format it as swap, and activate it.

* **Step 1: Allocate space for the file.** Create an 8GB swap file using `fallocate` (adjust `8G` to `4G` or `16G` as required):
```bash
sudo fallocate -l 8G /swapfile

```


* **Step 2: Restrict file permissions.** Secure the swap file so regular users cannot read system memory data dumped to disk:
```bash
sudo chmod 600 /swapfile

```


* **Step 3: Format as swap.** Prepare the dedicated file system for Linux swap usage:
```bash
sudo mkswap /swapfile

```


* **Step 4: Turn swap on.** Activate the newly formatted file immediately:
```bash
sudo swapon /swapfile

```



---

## 4. Making Swap Activation Permanent

To ensure your swap file mounts automatically every time your computer starts, you must append its entry to the filesystem table (`/etc/fstab`).

1. Open `/etc/fstab` in the Nano editor:
```bash
sudo nano /etc/fstab
```

2. Scroll to the bottom of the file and paste this exact line:
```text
/swapfile none swap sw 0 0
```

3. Press **Ctrl+O** then **Enter** to save, and **Ctrl+X** to exit.
Alternatively, you can append the line directly via the command line:
```bash
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

## 5. Understanding and Optimizing Swappiness

Swappiness is a kernel parameter (ranging from 0 to 100) that controls how aggressively Linux transfers data from RAM into swap space.

| Swappiness Value | Behavior | Ideal Use Case |
| --- | --- | --- |
| **0 to 10** | Minimal swap usage; keeps processes in RAM as long as possible. | Desktop systems with adequate RAM and fast storage. |
| **60** | System default; balances RAM clearing and swap usage. | Standard server configurations and general usage. |
| **100** | Aggressive swap usage; moves inactive memory pages to swap rapidly. | Highly constrained systems with minimal physical RAM. |

To change swappiness temporarily to **10**:

```bash
sudo sysctl vm.swappiness=10

```

To make the swappiness setting permanent across system restarts:

```bash
echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf
```
---
## 6. Complete All-In-One Execution Command

If you want to create an 8GB swap file, set secure permissions, format it, enable it, append it to `/etc/fstab`, adjust swappiness to 10 permanently, and confirm status in a single step, copy and run this unified block:

```bash
sudo fallocate -l 8G /swapfile && \
sudo chmod 600 /swapfile && \
sudo mkswap /swapfile && \
sudo swapon /swapfile && \
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab && \
sudo sysctl vm.swappiness=10 && \
echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf && \
free -h && cat /proc/sys/vm/swappiness
```
