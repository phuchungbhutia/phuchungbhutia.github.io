Configuring Browser Proxies and Bypassing Local DNS Restrictions for Sikkim Government Portals

August 4, 2026 · 4 min · Phuchung Bhutia
Table of Contents
  • Understanding the Network Baseline
  • Part 1: System-Wide and Browser Proxy Configuration
    • 1. Windows System-Wide Setup

Navigating government portals often requires specific network configurations, particularly when local domain names rely on internal National Informatics Centre (NIC) DNS infrastructure. If you are accessing services like the Sikkim DDO Pranali portal (ddo.pranali.sikkim.nic.in) through a proxy setup, misconfigured DNS settings can lead to domain resolution failures or local DNS leaks.

This detailed guide breaks down how to configure system-wide and browser-specific proxies in Firefox and Opera, and how to set up FoxyProxy Standard to safely route NIC DNS traffic.

Understanding the Network Baseline#

Before configuring your proxy, it is essential to understand the active Ethernet interface parameters typical for this environment:

  • Active IP Address: Assigned via static network configuration.
  • Primary NIC DNS Server: 164.100.3.1
  • Secondary NIC DNS Server: 164.100.17.3

Because these specific NIC DNS servers handle internal .nic.in subdomains, setting up a web proxy requires ensuring that DNS lookups are either proxied remotely or properly routed so that internal portal names resolve correctly.

Part 1: System-Wide and Browser Proxy Configuration#

1. Windows System-Wide Setup#

Routing web traffic through a system proxy while retaining static network settings:

  1. Open Settings on your Windows machine.
  2. Go to Network & Internet > Proxy.
  3. Under Manual proxy setup, click Set up next to Use a proxy server.
  4. Toggle Use a proxy server to On.
  5. Enter your Proxy IP Address and Port.
  6. In the Exceptions box, add internal domains and subnets to bypass unnecessary proxying if needed:
    10.*; *.nic.in; *.sikkim.nic.in


7. Click **Save**.

#### 2. Native Firefox Setup

Firefox manages its own network stack independently of the host OS:

1. Open Firefox, go to **Settings** > **General**, and scroll down to **Network Settings**.
2. Click **Settings...**
3. Choose **Manual proxy configuration**.
4. Enter your proxy host IP and Port number.
5. If using a SOCKS proxy, check the box **Proxy DNS when using SOCKS v5**.
* *Alternative via `about:config*`: Search for `network.proxy.socks_remote_dns` and set its value to `true`.



#### 3. Native Opera Setup

Opera utilizes the host system’s network configuration:

1. Open Opera **Settings**.
2. Navigate to **Advanced** > **System**.
3. Click **Open your computer's proxy settings** to launch the Windows Proxy menu.
4. Set up your manual proxy address and port as outlined in the Windows setup steps above.

### Part 2: Advanced Browser Routing using FoxyProxy Standard

Using an extension like **FoxyProxy Standard** gives you granular control over which domains use the proxy and prevents local DNS leaks.

#### Step-by-Step FoxyProxy Configuration

1. **Open Options**: Click the FoxyProxy icon in your browser toolbar and select **Options**.
2. **Add Configuration**: Click the **Add** button in the left panel.
3. **Fill Configuration Fields**:
* **Proxy Type**: Select **SOCKS5** (recommended for full DNS proxying) or **HTTP**.
* **Title**: Enter a descriptive name (e.g., `NIC Office Proxy`).
* **Proxy IP Address / Hostname**: Enter your proxy server IP (e.g., `127.0.0.1` for a local tunnel, or your local network proxy IP address such as `10.182.x.x`).
* **Port**: Enter the matching port (e.g., `1080` for SOCKS5, or `8080`/`3128` for HTTP).
* **Username / Password**: Complete only if your proxy server requires authentication.


4. **Enable Proxy DNS (Crucial)**:
* Scroll down to the **Proxy DNS** toggle and switch it to **ON** (enabled). This forces domain resolutions for sites like `ddo.pranali.sikkim.nic.in` through the proxy tunnel rather than risking a drop-off at the local network interface.


5. **Save and Activate**:
* Click **Save**.
* Click the FoxyProxy toolbar icon and switch mode to **Use proxy [NIC Office Proxy] for all URLs** or set up **Proxy by Patterns** for `*.nic.in` domains specifically.
