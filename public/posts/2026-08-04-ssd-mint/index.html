Navigating Linux Mint often comes with two common scenarios: managing secure, encrypted storage and customizing software features that aren’t enabled out of the box. Below is a comprehensive guide covering how to seamlessly access LUKS-encrypted SSDs and how to forcibly enable the Microsoft Edge Copilot sidebar using a simple custom script.

Guide 1: How to Open an Encrypted SSD in Linux Mint#

Linux Mint relies on LUKS (Linux Unified Key Setup) as its standard disk encryption specification. Accessing your encrypted SSD can be handled via the graphical user interface (GUI) for ease of use or through the terminal for manual control and troubleshooting.

Method 1: Using the GUI File Manager (Nemo)#

  1. Connect your external or secondary encrypted SSD to your computer.
  2. Open Nemo (the default file manager in Linux Mint).
  3. Look at the left sidebar under the Devices section. Locate your encrypted drive (it often displays a padlock icon).
  4. Click on the drive name.
  5. A system prompt will appear asking for your encryption passphrase. Enter it and click Unlock.
  6. Linux Mint automatically mounts the decrypted volume, making it accessible like any standard folder.

Method 2: Opening via the Terminal#

When managing servers or troubleshooting unmountable drives, the terminal gives you full control over the cryptsetup tool.

Step 1: Identify the Partition#

List all attached block devices to locate the encrypted partition identifier (e.g., /dev/sdb1 or /dev/nvme0n1p2):

lsblk

Step 2: Open the Encrypted LUKS Container#

Decrypted volumes are mapped into /dev/mapper/. Run the following command to decrypt the target partition:

sudo cryptsetup luksOpen /dev/sdXY my_encrypted_drive

(Replace /dev/sdXY with your actual partition name, such as /dev/sdb1.)

Step 3: Create a Mount Point & Mount the Volume#

Once decrypted, create a directory and mount the mapped drive:

sudo mkdir -p /mnt/my_ssd
sudo mount /dev/mapper/my_encrypted_drive /mnt/my_ssd

Fixing Ownership Issues#

If you can read the files on your mounted SSD but cannot write or modify them, update the directory permissions to match your current Linux Mint user:

sudo chown -R $USER:$USER /mnt/my_ssd

Safely Dismounting and Closing the Volume#

Never unplug an encrypted drive while it is mapped. Follow these steps to cleanly close the container:

# 1. Unmount the directory
sudo umount /mnt/my_ssd

# 2. Lock the LUKS container
sudo cryptsetup luksClose my_encrypted_drive

Guide 2: Enabling Microsoft Edge Copilot Sidebar on Linux Mint#

By default, Microsoft Edge on Linux omits or hides the integrated Copilot sidebar. You can bypass this limitation by generating a specific hubapps.json configuration file and passing a feature flag at launch.

Optimized Bash Script#

The following bash script checks for both stable and development Edge installation paths, builds the necessary Default/HubApps directory structure, and injects the Copilot app configuration.

#!/bin/bash
# Refined Edge Copilot Enabler for Linux Mint

# Detect Edge config directory
if [ -d "$HOME/.config/microsoft-edge" ]; then
    EDGE_PATH="$HOME/.config/microsoft-edge"
elif [ -d "$HOME/.config/microsoft-edge-dev" ]; then
    EDGE_PATH="$HOME/.config/microsoft-edge-dev"
else
    echo "❌ Error: Microsoft Edge configuration directory not found."
    exit 1
fi

HUB_DIR="$EDGE_PATH/Default/HubApps"
mkdir -p "$HUB_DIR"

# Write the Copilot app manifest
cat <<EOF> "$HUB_DIR/hubapps.json"
{
  "isSidebarEnabled": true,
  "sidebarApps": [
    {
      "id": "copilot",
      "name": "Copilot",
      "url": "[https://copilot.microsoft.com](https://copilot.microsoft.com)"
    }
  ]
}
EOF

echo "✅ Copilot config successfully written to $HUB_DIR/hubapps.json"
echo "🚀 Launch Edge using: microsoft-edge --enable-features=msHubApps"

Making the Change Permanent in Linux Mint#

To avoid running Edge from the terminal every time you want the Copilot sidebar:

  1. Right-click the Linux Mint Menu icon in your panel and select Configure.
  2. Navigate to the Menu tab and click Open the menu editor.
  3. Go to the Internet category and select Microsoft Edge.
  4. Click Properties.
  5. Update the Command field to append the required flag at the end:
/usr/bin/microsoft-edge-stable %U --enable-features=msHubApps
  1. Save your changes and close the editor. Opening Edge from your main application panel will now always include the sidebar feature.
