Complete Guide: How to Clean Up Windows Using Command Prompt (CMD)

Over time, any Windows installation accumulates unnecessary junk files, temporary data, corrupted cache, and outdated system updates that can slow down your PC’s performance. While Windows offers various graphical user interface (GUI) tools like Settings and Disk Cleanup, using the Command Prompt (CMD) allows you to perform deep, thorough maintenance quickly and efficiently.

This detailed guide breaks down the essential CMD tools and commands to reclaim storage space, fix system integrity, and speed up your machine.

1. Deleting Temporary and Prefetch Files#

Windows stores temporary operational data across several system directories. Over time, these folders can grow to tens of gigabytes. Deleting their contents is safe and immediately frees up storage.

Note: To run these commands, open Command Prompt as an Administrator (Search cmd, right-click Command Prompt, and select Run as administrator).

Commands#

del /q /f /s %systemroot%\temp\*
del /q /f /s %temp%\*
del /q /f /s %systemroot%\Prefetch\*

Explanation of Command Flags#

  • /q (Quiet mode): Suppresses confirmation prompts so the system doesn’t ask “Are you sure?” for every file.
  • /f (Force): Forces the deletion of read-only files.
  • /s (Subdirectories): Deletes specified files from the current directory and all of its subdirectories.

2. Windows Disk Cleanup Utility (cleanmgr)#

Windows includes a built-in tool called cleanmgr. Running it from the command line allows you to trigger automated disk cleanup routines.

Commands#

  • Run pre-configured cleanup:
cleanmgr /sagerun:1
  • Run automated low-disk cleanup:
cleanmgr /lowdisk

3. Servicing the Component Store (DISM)#

When Windows updates run, older versions of components are kept in the WinSxS (Windows Side-by-Side) folder. If left unchecked, this folder can consume massive amounts of disk space. The Deployment Image Servicing and Management (DISM) tool handles this cleanup safely.

Commands#

  • Analyze Component Store:
dism /Online /Cleanup-Image /AnalyzeComponentStore
  • Start Component Cleanup:
dism /Online /Cleanup-Image /StartComponentCleanup

4. Checking and Repairing System File Integrity (SFC)#

System slowness or unexpected crashes are often caused by corrupted core system files rather than just disk space issues. The System File Checker (SFC) utility scans all protected system files and replaces corrupted files with a cached copy.

Command#

sfc /scannow

5. Flushing the Network DNS Cache#

If you are experiencing network lag or slow web page loads, clearing your local DNS resolution cache can fix routing conflicts and improve response times.

Command#

ipconfig /flushdns

6. Drive Optimization and TRIM (defrag)#

Optimizing your drive rearranges file fragments on standard Hard Disk Drives (HDDs) to speed up read/write operations. For Solid State Drives (SSDs), running this command sends a TRIM instruction, informing the drive which data blocks are no longer in use so they can be reclaimed internally.

Command#

defrag C: /O

Parameter /O: Performs the proper optimization for your specific drive type (Defragmentation for HDDs, TRIM for SSDs).

Quick Reference: One-Liner Script#

If you want to execute the complete cleanup routine in a single run, copy and paste the following sequential block into an elevated Command Prompt:

del /q /f /s %systemroot%\temp\* & del /q /f /s %temp%\* & del /q /f /s %systemroot%\Prefetch\* & dism /online /cleanup-image /startcomponentcleanup & sfc /scannow & ipconfig /flushdns & defrag C: /O
