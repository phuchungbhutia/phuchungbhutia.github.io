# Printing Pocket Booklets from Markdown Without Touching LaTeX or Pandoc

If you have ever tried to turn a Markdown file into a printable, folded A5 booklet on Windows or Linux, you know the pain. Usually, the standard advice sends you down a rabbit hole of heavy toolchains. You install Pandoc. Then you install a multi-gigabyte TeX Live distribution just to get xelatex. Then you realize xelatex outputs single A5 pages, so you install Poppler and pdfjam—or worse, a third-party GUI tool—just to shuffle the pages into saddle-stitch order so they fold properly out of an A4 printer.

It works, eventually. Until you switch machines, upgrade your OS, or try to run it on a clean Windows box without WSL.

There is a much cleaner way. Using just Python and two lightweight libraries (PyMuPDF and markdown), you can build a self-contained CLI tool that paginates Markdown into A5 sheets, adds automatic page numbering, and imposes the pages into a print-ready A4 landscape saddle-stitch PDF in under two seconds. Zero external binaries. Zero TeX installations. Identical output on Windows, Linux, and macOS.

## Why PyMuPDF's Story Engine Changes Everything

Most Python PDF libraries fall into two camps:

* Canvas libraries (like ReportLab or fpdf2), where you manually calculate X/Y coordinates and wrap text lines yourself.
* Browser wrappers (like WeasyPrint or Playwright), which require GTK/Pango system DLLs or a headless Chromium binary.

PyMuPDF (fitz) includes a built-in layout engine called `fitz.Story`. It accepts standard HTML5 and CSS, handles flowing text, tables, code blocks, and page breaks automatically, and renders straight into native PDF vector graphics inside the same C-backed library.

That means our entire pipeline lives in memory:

```text
Markdown (.md) ──▶ HTML5 + CSS ──▶ fitz.Story (A5 Pages) ──▶ 2-Up Imposition ──▶ A4 Booklet (.pdf)
```

## Step 1: The Saddle-Stitch Imposition Math

When you print a booklet on standard A4 paper (297 mm × 210 mm) and fold the stack in half, each sheet of paper holds four A5 pages (148 mm × 210 mm): two on the front and two on the back. Because the sheets nest inside one another when folded, the pages cannot be printed in 1, 2, 3, 4 order. Instead, the outermost sheet holds the very first and very last pages, while the innermost sheet holds the center spread.

First, any document must be padded to a multiple of 4 pages:

$$ P = \lceil N / 4 \rceil \times 4 $$

Where $N$ is the actual number of rendered A5 pages, and $P$ is the padded total (any page index $\ge N$ simply stays blank at the back of the booklet).

For each physical sheet $s \in \{0, 1, \dots, \frac{P}{4} - 1\}$ using 0-based page indices:

* Front of Sheet s: Left slot gets page $P - 1 - 2s$, Right slot gets page $2s$
* Back of Sheet s: Left slot gets page $2s + 1$, Right slot gets page $P - 2 - 2s$

For an 8-page booklet ($P = 8$), that gives:

* Sheet 1 Front: [Page 8, Page 1]
* Sheet 1 Back: [Page 2, Page 7]
* Sheet 2 Front: [Page 6, Page 3]
* Sheet 2 Back: [Page 4, Page 5]

Print those two sheets double-sided, fold them down the middle, staple the spine, and every page reads in exact sequential order.

## Step 3: Rendering Markdown to Virtual A5 Pages

The first stage converts raw Markdown (with support for tables, fenced code blocks, and sane lists) into HTML, wraps it in clean print CSS, and flows it through `fitz.Story`.

Notice the margins: we use a 16 mm left margin and a 12 mm right margin. That extra 4 mm on the left acts as a binding gutter so text isn't swallowed by the center fold or staples. We also skip the footer page number on Page 1 so the cover stays clean.

```python
import math
from pathlib import Path
import fitz  # PyMuPDF
import markdown

MM_TO_PT = 72.0 / 25.4


def render_markdown_to_a5(md_path: Path, font_family: str = "sans-serif", font_size: float = 10.0) -> bytes:
    """Render Markdown directly into A5 portrait PDF bytes in memory."""
    raw_md = md_path.read_text(encoding="utf-8-sig")
    html_body = markdown.markdown(
        raw_md, extensions=["tables", "fenced_code", "nl2br", "sane_lists"]
    )

    css = f"""
    body {{
        font-family: "{font_family}", sans-serif;
        font-size: {font_size}pt;
        line-height: 1.35;
        color: #111111;
    }}
    h1 {{
        font-size: {font_size * 1.6:.1f}pt;
        margin-top: 0;
        margin-bottom: 8pt;
        border-bottom: 1pt solid #cccccc;
        padding-bottom: 4pt;
    }}
    h2 {{ font-size: {font_size * 1.3:.1f}pt; margin-top: 12pt; margin-bottom: 6pt; }}
    p  {{ margin-top: 0; margin-bottom: 8pt; }}
    pre, code {{
        font-family: monospace;
        font-size: {font_size * 0.85:.1f}pt;
        background-color: #f4f4f4;
    }}
    pre {{ padding: 6pt; border: 0.5pt solid #dddddd; }}
    table {{ width: 100%; border-collapse: collapse; margin: 8pt 0; font-size: {font_size * 0.9:.1f}pt; }}
    th, td {{ border: 0.5pt solid #bbbbbb; padding: 4pt 6pt; text-align: left; }}
    th {{ background-color: #eeeeee; font-weight: bold; }}
    """

    full_html = f"<!DOCTYPE html><html><head><meta charset='utf-8'><style>{css}</style></head><body>{html_body}</body></html>"

    a5_rect = fitz.paper_rect("a5")
    content_rect = fitz.Rect(
        16 * MM_TO_PT,
        14 * MM_TO_PT,
        a5_rect.width - (12 * MM_TO_PT),
        a5_rect.height - (14 * MM_TO_PT),
    )

    story = fitz.Story(html=full_html)
    out_doc = fitz.open()
    page_num = 0

    try:
        while True:
            page_num += 1
            page = out_doc.new_page(width=a5_rect.width, height=a5_rect.height)
            more, _ = story.place(content_rect)
            story.draw(page)

            if page_num > 1:
                footer_rect = fitz.Rect(
                    0,
                    a5_rect.height - (10 * MM_TO_PT),
                    a5_rect.width,
                    a5_rect.height - (4 * MM_TO_PT),
                )
                page.insert_textbox(
                    footer_rect,
                    str(page_num),
                    fontsize=8.0,
                    fontname="helv",
                    color=(0.35, 0.35, 0.35),
                    align=fitz.TEXT_ALIGN_CENTER,
                )

            if not more:
                break

        return out_doc.tobytes()
    finally:
        out_doc.close()
```

A subtle detail worth noting: reading with `encoding="utf-8-sig"` automatically strips the Byte Order Mark (BOM) if a Markdown file was saved by Windows Notepad or PowerShell's `Set-Content -Encoding UTF8`, preventing stray invisible characters at the top of Page 1.

## Step 4: Imposing onto A4 Landscape Sheets

Once we have the virtual A5 PDF in memory as bytes, PyMuPDF's `show_pdf_page()` lets us stamp vector copies of each A5 page onto the left and right halves of an A4 landscape canvas (`a4-l`). Because `show_pdf_page()` copies vector primitives and fonts directly without rasterizing, the final text stays razor-sharp at any DPI.

```python
def calculate_imposition_pairs(total_pages: int) -> list[tuple[int, int]]:
    """Compute 0-based (left_idx, right_idx) pairs for saddle-stitch imposition."""
    padded_total = math.ceil(total_pages / 4) * 4
    pairs: list[tuple[int, int]] = []

    for sheet in range(padded_total // 4):
        front_left = padded_total - 1 - (2 * sheet)
        front_right = 2 * sheet
        back_left = 2 * sheet + 1
        back_right = padded_total - 2 - (2 * sheet)
        pairs.append((front_left, front_right))
        pairs.append((back_left, back_right))

    return pairs


def impose_to_a4_booklet(a5_pdf_bytes: bytes, output_path: Path) -> int:
    """Impose A5 portrait pages onto A4 landscape sheets in saddle-stitch order."""
    src_doc = fitz.open(stream=a5_pdf_bytes, filetype="pdf")
    booklet_doc = fitz.open()

    try:
        total_pages = len(src_doc)
        pairs = calculate_imposition_pairs(total_pages)

        a4_rect = fitz.paper_rect("a4-l")
        half_w = a4_rect.width / 2.0
        full_h = a4_rect.height
        left_slot = fitz.Rect(0, 0, half_w, full_h)
        right_slot = fitz.Rect(half_w, 0, a4_rect.width, full_h)

        for left_idx, right_idx in pairs:
            sheet_page = booklet_doc.new_page(width=a4_rect.width, height=full_h)
            if left_idx < total_pages:
                sheet_page.show_pdf_page(left_slot, src_doc, left_idx)
            if right_idx < total_pages:
                sheet_page.show_pdf_page(right_slot, src_doc, right_idx)

        output_path.parent.mkdir(parents=True, exist_ok=True)
        booklet_doc.save(str(output_path), garbage=4, deflate=True)
        return len(booklet_doc)
    finally:
        booklet_doc.close()
        src_doc.close()
```

Passing `garbage=4, deflate=True` on `.save()` deduplicates shared font subsets across imposed pages and compresses the PDF streams, keeping typical field guides and reference booklets well under 100 KB.

## Step 5: Verifying the Imposition Math with pytest

Off-by-one bugs in imposition algorithms waste paper fast. A quick unit test guarantees that both exact multiples of 4 and padded documents (such as a 5-page document padded to 8 slots) map to the exact right sheet positions:

```python
from src.main import calculate_imposition_pairs


def test_imposition_pairs_4_pages() -> None:
    assert calculate_imposition_pairs(4) == [(3, 0), (1, 2)]


def test_imposition_pairs_with_padding() -> None:
    # 5 pages pad to 8 slots; indices 5, 6, and 7 render as blank pages
    assert calculate_imposition_pairs(5) == [
        (7, 0),  # Sheet 1 Front: [Blank, Page 1]
        (1, 6),  # Sheet 1 Back:  [Page 2, Blank]
        (5, 2),  # Sheet 2 Front: [Blank, Page 3]
        (3, 4),  # Sheet 2 Back:  [Page 4, Page 5]
    ]
```

## Step 6: Generating and Printing Your Booklet

Run the CLI against any Markdown file:

```bash
# Default 10pt sans-serif
python -m src.main input/sample.md

# Custom serif typography and output path
python -m src.main input/field_manual.md --font "Georgia" --size 10.5 -o output/field_manual_booklet.pdf
```

When sending the generated PDF to your printer, use these three settings:

* Paper Size: A4
* Scale: 100% (Actual Size — do not use "Fit to Printable Area", which shrinks your margins)
* Two-Sided / Duplex: Flip on Short Edge

That last setting is the most common gotcha. Standard portrait documents flip on the long edge; because our imposed sheets are landscape, flipping on the long edge will print the back of every sheet upside down. Selecting **Flip on Short Edge** keeps both sides aligned so you can pull the stack straight off the tray, fold it down the center crease, and staple the spine.

## Where to Take It Next

Because the entire rendering pipeline is standard HTML and CSS inside `fitz.Story`, you can extend `md2booklet` without touching the imposition engine:

* CSS Page Breaks: Inject `<div style="page-break-before: always;"></div>` or style `h1 { page-break-before: always; }` so major chapters always start on a fresh A5 page.
* Custom Title Pages: Detect a YAML front-matter block (title, subtitle, date) and render a centered cover block on Page 1 before flowing body sections.
* Batch Compilation: Loop over a folder of Markdown notes to compile an entire pocket reference library in one command.

from __future__ import annotations

import argparse
import logging
import math
import os

from typing import Any

import fitz  # PyMuPDF
import markdown
import yaml

MM_TO_PT = 72.0 / 25.4
LOGGER = logging.getLogger("md2booklet")


@dataclass
class BookletConfig:
    """Runtime configuration for rendering and saddle-stitch imposition."""

    font_family: str = "sans-serif"
    font_size_pt: float = 10.0
    line_height: float = 1.35
    text_color: str = "#111111"
    source_paper: str = "a5"
    target_paper: str = "a4-l"
    margin_left_mm: float = 16.0
    margin_top_mm: float = 14.0
    margin_right_mm: float = 12.0
    margin_bottom_mm: float = 14.0
    show_page_numbers: bool = True
    footer_font_size_pt: float = 8.0
    extensions: list[str] = field(
        default_factory=lambda: ["tables", "fenced_code", "nl2br", "sane_lists"]

def setup_logging(level_name: str | None = None) -> None:
    """Configure structured console logging."""
    raw_level = (level_name or os.getenv("MD2BOOKLET_LOG_LEVEL", "INFO")).upper()
    numeric_level = getattr(logging, raw_level, logging.INFO)
    logging.basicConfig(

        format="%(asctime)s [%(levelname)s] %(message)s",

def load_config(config_path: Path | None = None) -> BookletConfig:
    """Load configuration from YAML and apply environment variable overrides."""
    cfg = BookletConfig()

    resolved_path = config_path or Path(
        os.getenv("MD2BOOKLET_CONFIG", "config/settings.yaml")
    )
    if resolved_path.is_file():
        try:
            raw_data: dict[str, Any] = (
                yaml.safe_load(resolved_path.read_text(encoding="utf-8")) or {}
            )
            typo = raw_data.get("typography", {})
            layout = raw_data.get("layout", {})
            margins = layout.get("margins_mm", {})
            md_cfg = raw_data.get("markdown", {})
            out_cfg = raw_data.get("output", {})

            cfg.font_family = str(typo.get("font_family", cfg.font_family))
            cfg.font_size_pt = float(typo.get("font_size_pt", cfg.font_size_pt))
            cfg.line_height = float(typo.get("line_height", cfg.line_height))
            cfg.text_color = str(typo.get("text_color", cfg.text_color))

            cfg.source_paper = str(layout.get("source_paper", cfg.source_paper))
            cfg.target_paper = str(layout.get("target_paper", cfg.target_paper))
            cfg.margin_left_mm = float(margins.get("left", cfg.margin_left_mm))
            cfg.margin_top_mm = float(margins.get("top", cfg.margin_top_mm))
            cfg.margin_right_mm = float(margins.get("right", cfg.margin_right_mm))
            cfg.margin_bottom_mm = float(margins.get("bottom", cfg.margin_bottom_mm))
            cfg.show_page_numbers = bool(
                layout.get("show_page_numbers", cfg.show_page_numbers)
            )
            cfg.footer_font_size_pt = float(
                layout.get("footer_font_size_pt", cfg.footer_font_size_pt)
            )

    }}

def render_markdown_to_a5(md_path: Path, cfg: BookletConfig) -> bytes:
    """Render a Markdown file directly into A5 portrait PDF bytes in memory."""
    if not md_path.is_file():
        raise FileNotFoundError(f"Markdown input file not found: {md_path}")

    raw_md = md_path.read_text(encoding="utf-8-sig")
    if not raw_md.strip():
        raise ValueError(f"Markdown input file is empty: {md_path}")

    full_html = build_html_document(raw_md, cfg)
    a5_rect = fitz.paper_rect(cfg.source_paper)

    content_rect = fitz.Rect(
        cfg.margin_left_mm * MM_TO_PT,
        cfg.margin_top_mm * MM_TO_PT,
        a5_rect.width - (cfg.margin_right_mm * MM_TO_PT),
        a5_rect.height - (cfg.margin_bottom_mm * MM_TO_PT),
    )
    if content_rect.is_empty or content_rect.width <= 0 or content_rect.height <= 0:
        raise ValueError("Configured margins exceed page dimensions.")

    story = fitz.Story(html=full_html)
    out_doc = fitz.open()
    page_num = 0

    try:
        while True:
            page_num += 1
            page = out_doc.new_page(width=a5_rect.width, height=a5_rect.height)
            more, _ = story.place(content_rect)
            story.draw(page)

            if cfg.show_page_numbers and page_num > 1:
                footer_rect = fitz.Rect(
                    0,
                    a5_rect.height - (10 * MM_TO_PT),
                    a5_rect.width,
                    a5_rect.height - (4 * MM_TO_PT),
                )
                page.insert_textbox(
                    footer_rect,
                    str(page_num),
                    fontsize=cfg.footer_font_size_pt,
                    fontname="helv",
                    color=(0.35, 0.35, 0.35),
                    align=fitz.TEXT_ALIGN_CENTER,
                )

            if not more:
                break

        return out_doc.tobytes()
    finally:
        out_doc.close()


def calculate_imposition_pairs(total_pages: int) -> list[tuple[int, int]]:
    """Compute (left_page_idx, right_page_idx) 0-based pairs for saddle-stitch imposition."""
    if total_pages <= 0:
        raise ValueError("Total pages must be greater than zero.")

    padded_total = math.ceil(total_pages / 4) * 4
    pairs: list[tuple[int, int]] = []

    for sheet in range(padded_total // 4):
        front_left = padded_total - 1 - (2 * sheet)
        front_right = 2 * sheet
        back_left = 2 * sheet + 1
        back_right = padded_total - 2 - (2 * sheet)
        pairs.append((front_left, front_right))
        pairs.append((back_left, back_right))

    return pairs


def impose_to_a4_booklet(
    a5_pdf_bytes: bytes, output_path: Path, cfg: BookletConfig
) -> int:
    """Impose A5 portrait pages onto A4 landscape sheets in saddle-stitch order."""
    src_doc = fitz.open(stream=a5_pdf_bytes, filetype="pdf")
    booklet_doc = fitz.open()

    try:
        total_pages = len(src_doc)
        pairs = calculate_imposition_pairs(total_pages)

        a4_rect = fitz.paper_rect(cfg.target_paper)
        half_w = a4_rect.width / 2.0
        full_h = a4_rect.height
        left_slot = fitz.Rect(0, 0, half_w, full_h)
        right_slot = fitz.Rect(half_w, 0, a4_rect.width, full_h)

        for left_idx, right_idx in pairs:
            sheet_page = booklet_doc.new_page(width=a4_rect.width, height=full_h)
            if left_idx < total_pages:
                sheet_page.show_pdf_page(left_slot, src_doc, left_idx)
            if right_idx < total_pages:
                sheet_page.show_pdf_page(right_slot, src_doc, right_idx)

        output_path.parent.mkdir(parents=True, exist_ok=True)
        booklet_doc.save(
            str(output_path),
            garbage=cfg.garbage_collection,
            deflate=cfg.deflate,
        )
        return len(booklet_doc)
    finally:
        booklet_doc.close()
        src_doc.close()


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    """Parse command-line interface arguments."""
    parser = argparse.ArgumentParser(
        prog="md2booklet",
        description="Convert Markdown to an A4 saddle-stitch PDF booklet.",
    )
    parser.add_argument("input_md", help="Path to input .md file")
    parser.add_argument("-c", "--config", type=Path, default=None, help="Path to YAML config file")
    parser.add_argument("-f", "--font", default=None, help="Override body font family")
    parser.add_argument("-s", "--size", type=float, default=None, help="Override body font size in pt")
    parser.add_argument("-o", "--output", type=Path, default=None, help="Custom output PDF path")
    parser.add_argument("--no-page-numbers", action="store_true", help="Disable footer page numbers")
    parser.add_argument("--log-level", default=None, choices=["DEBUG", "INFO", "WARNING", "ERROR"])
    return parser.parse_args(argv)


def main(argv: list[str] | None = None) -> int:
    """CLI execution pipeline."""
    args = parse_args(argv)
    setup_logging(args.log_level)

    try:
        cfg = load_config(args.config)
        if args.font is not None:
            cfg.font_family = args.font
        if args.size is not None:
            if args.size <= 0:
                raise ValueError("Font size must be a positive number.")
            cfg.font_size_pt = args.size
        if args.no_page_numbers:
            cfg.show_page_numbers = False

        md_path = Path(args.input_md)
        out_path = args.output or (
            Path(cfg.output_dir) / f"{md_path.stem}{cfg.output_suffix}.pdf"
        )

        LOGGER.info("[1/2] Rendering '%s' to A5 pages (%s, %.1fpt)...", md_path.name, cfg.font_family, cfg.font_size_pt)
        a5_bytes = render_markdown_to_a5(md_path, cfg)

        LOGGER.info("[2/2] Imposing pages onto A4 landscape booklet...")
        imposed_pages = impose_to_a4_booklet(a5_bytes, out_path, cfg)

        LOGGER.info("Done! Saved %d imposed pages to: %s", imposed_pages, out_path)
        LOGGER.info("Print tip: Enable Two-Sided printing and select 'Flip on Short Edge'.")
        return 0

    except (FileNotFoundError, ValueError, RuntimeError) as exc:
        LOGGER.error("%s", exc)
        return 1


if __name__ == "__main__":
    sys.exit(main())

"""Pre-build and pre-commit validation gate for md2booklet."""

from __future__ import annotations

import sys
from pathlib import Path
import yaml

REPO_ROOT = Path(__file__).resolve().parent.parent


def validate_markdown_inputs() -> list[str]:
    errors: list[str] = []
    input_dir = REPO_ROOT / "input"
    if not input_dir.is_dir():
        return errors
    for md_file in sorted(input_dir.rglob("*.md")):
        try:
            content = md_file.read_text(encoding="utf-8-sig")
            if not content.strip():
                errors.append(f"[MARKDOWN] Empty file: {md_file.relative_to(REPO_ROOT)}")
        except UnicodeDecodeError as exc:
            errors.append(f"[MARKDOWN] Invalid UTF-8 encoding in {md_file.relative_to(REPO_ROOT)}: {exc}")
    return errors


def validate_yaml_files() -> list[str]:
    errors: list[str] = []
    targets = list((REPO_ROOT / "config").glob("*.y*ml")) + list((REPO_ROOT / ".github").rglob("*.y*ml"))
    for yaml_file in sorted(targets):
        try:
            yaml.safe_load(yaml_file.read_text(encoding="utf-8"))
        except yaml.YAMLError as exc:
            errors.append(f"[YAML] Syntax error in {yaml_file.relative_to(REPO_ROOT)}: {exc}")
    return errors


def main() -> int:
    all_errors = validate_markdown_inputs() + validate_yaml_files()
    if all_errors:
        print("Validation failed:", file=sys.stderr)
        for err in all_errors:
            print(f"  - {err}", file=sys.stderr)
        return 1
    print("Validation passed: All Markdown inputs and YAML configs are well-formed.")
    return 0


if __name__ == "__main__":
    sys.exit(main())

def render_markdown_to_a5(md_path: Path, cfg: BookletConfig) -> bytes:
    """Render a Markdown file directly into A5 portrait PDF bytes in memory."""
    if not md_path.is_file():
        raise FileNotFoundError(f"Markdown input file not found: {md_path}")

    raw_md = md_path.read_text(encoding="utf-8-sig")
    if not raw_md.strip():
        raise ValueError(f"Markdown input file is empty: {md_path}")

    full_html = build_html_document(raw_md, cfg)
    a5_rect = fitz.paper_rect(cfg.source_paper)

    content_rect = fitz.Rect(
        cfg.margin_left_mm * MM_TO_PT,
        cfg.margin_top_mm * MM_TO_PT,
        a5_rect.width - (cfg.margin_right_mm * MM_TO_PT),
        a5_rect.height - (cfg.margin_bottom_mm * MM_TO_PT),
    )
    if content_rect.is_empty or content_rect.width <= 0 or content_rect.height <= 0:
        raise ValueError("Configured margins exceed page dimensions.")

    story = fitz.Story(html=full_html)
    out_doc = fitz.open()
    page_num = 0

    try:
        while True:
            page_num += 1
            page = out_doc.new_page(width=a5_rect.width, height=a5_rect.height)
            more, _ = story.place(content_rect)
            story.draw(page)

            if cfg.show_page_numbers and page_num > 1:
                footer_rect = fitz.Rect(
                    0,
                    a5_rect.height - (10 * MM_TO_PT),
                    a5_rect.width,
                    a5_rect.height - (4 * MM_TO_PT),
                )
                page.insert_textbox(
                    footer_rect,
                    str(page_num),
                    fontsize=cfg.footer_font_size_pt,
                    fontname="helv",
                    color=(0.35, 0.35, 0.35),
                    align=fitz.TEXT_ALIGN_CENTER,
                )

            if not more:
                break

        return out_doc.tobytes()
    finally:
        out_doc.close()


def calculate_imposition_pairs(total_pages: int) -> list[tuple[int, int]]:
    """Compute (left_page_idx, right_page_idx) 0-based pairs for saddle-stitch imposition."""
    if total_pages <= 0:
        raise ValueError("Total pages must be greater than zero.")

    padded_total = math.ceil(total_pages / 4) * 4
    pairs: list[tuple[int, int]] = []

    for sheet in range(padded_total // 4):
        front_left = padded_total - 1 - (2 * sheet)
        front_right = 2 * sheet
        back_left = 2 * sheet + 1
        back_right = padded_total - 2 - (2 * sheet)
        pairs.append((front_left, front_right))
        pairs.append((back_left, back_right))

    return pairs


def impose_to_a4_booklet(
    a5_pdf_bytes: bytes, output_path: Path, cfg: BookletConfig
) -> int:
    """Impose A5 portrait pages onto A4 landscape sheets in saddle-stitch order."""
    src_doc = fitz.open(stream=a5_pdf_bytes, filetype="pdf")
    booklet_doc = fitz.open()

    try:
        total_pages = len(src_doc)
        pairs = calculate_imposition_pairs(total_pages)

        a4_rect = fitz.paper_rect(cfg.target_paper)
        half_w = a4_rect.width / 2.0
        full_h = a4_rect.height
        left_slot = fitz.Rect(0, 0, half_w, full_h)
        right_slot = fitz.Rect(half_w, 0, a4_rect.width, full_h)

        for left_idx, right_idx in pairs:
            sheet_page = booklet_doc.new_page(width=a4_rect.width, height=full_h)
            if left_idx < total_pages:
                sheet_page.show_pdf_page(left_slot, src_doc, left_idx)
            if right_idx < total_pages:
                sheet_page.show_pdf_page(right_slot, src_doc, right_idx)

        output_path.parent.mkdir(parents=True, exist_ok=True)
        booklet_doc.save(
            str(output_path),
            garbage=cfg.garbage_collection,
            deflate=cfg.deflate,
        )
        return len(booklet_doc)
    finally:
        booklet_doc.close()
        src_doc.close()


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    """Parse command-line interface arguments."""
    parser = argparse.ArgumentParser(
        prog="md2booklet",
        description="Convert Markdown to an A4 saddle-stitch PDF booklet.",
    )
    parser.add_argument("input_md", help="Path to input .md file")
    parser.add_argument("-c", "--config", type=Path, default=None, help="Path to YAML config file")
    parser.add_argument("-f", "--font", default=None, help="Override body font family")
    parser.add_argument("-s", "--size", type=float, default=None, help="Override body font size in pt")
    parser.add_argument("-o", "--output", type=Path, default=None, help="Custom output PDF path")
    parser.add_argument("--no-page-numbers", action="store_true", help="Disable footer page numbers")
    parser.add_argument("--log-level", default=None, choices=["DEBUG", "INFO", "WARNING", "ERROR"])
    return parser.parse_args(argv)


def main(argv: list[str] | None = None) -> int:
    """CLI execution pipeline."""
    args = parse_args(argv)
    setup_logging(args.log_level)

    try:
        cfg = load_config(args.config)
        if args.font is not None:
            cfg.font_family = args.font
        if args.size is not None:
            if args.size <= 0:
                raise ValueError("Font size must be a positive number.")
            cfg.font_size_pt = args.size
        if args.no_page_numbers:
            cfg.show_page_numbers = False

        md_path = Path(args.input_md)
        out_path = args.output or (
            Path(cfg.output_dir) / f"{md_path.stem}{cfg.output_suffix}.pdf"
        )

        LOGGER.info("[1/2] Rendering '%s' to A5 pages (%s, %.1fpt)...", md_path.name, cfg.font_family, cfg.font_size_pt)
        a5_bytes = render_markdown_to_a5(md_path, cfg)

        LOGGER.info("[2/2] Imposing pages onto A4 landscape booklet...")
        imposed_pages = impose_to_a4_booklet(a5_bytes, out_path, cfg)

        LOGGER.info("Done! Saved %d imposed pages to: %s", imposed_pages, out_path)
        LOGGER.info("Print tip: Enable Two-Sided printing and select 'Flip on Short Edge'.")
        return 0

    except (FileNotFoundError, ValueError, RuntimeError) as exc:
        LOGGER.error("%s", exc)
        return 1


if __name__ == "__main__":
    sys.exit(main())

"""Pre-build and pre-commit validation gate for md2booklet."""

from __future__ import annotations

import sys
from pathlib import Path
import yaml

REPO_ROOT = Path(__file__).resolve().parent.parent


def validate_markdown_inputs() -> list[str]:
    errors: list[str] = []
    input_dir = REPO_ROOT / "input"
    if not input_dir.is_dir():
        return errors
    for md_file in sorted(input_dir.rglob("*.md")):
        try:
            content = md_file.read_text(encoding="utf-8-sig")
            if not content.strip():
                errors.append(f"[MARKDOWN] Empty file: {md_file.relative_to(REPO_ROOT)}")
        except UnicodeDecodeError as exc:
            errors.append(f"[MARKDOWN] Invalid UTF-8 encoding in {md_file.relative_to(REPO_ROOT)}: {exc}")
    return errors


def validate_yaml_files() -> list[str]:
    errors: list[str] = []
    targets = list((REPO_ROOT / "config").glob("*.y*ml")) + list((REPO_ROOT / ".github").rglob("*.y*ml"))
    for yaml_file in sorted(targets):
        try:
            yaml.safe_load(yaml_file.read_text(encoding="utf-8"))
        except yaml.YAMLError as exc:
            errors.append(f"[YAML] Syntax error in {yaml_file.relative_to(REPO_ROOT)}: {exc}")
    return errors


def main() -> int:
    all_errors = validate_markdown_inputs() + validate_yaml_files()
    if all_errors:
        print("Validation failed:", file=sys.stderr)
        for err in all_errors:
            print(f"  - {err}", file=sys.stderr)
        return 1
    print("Validation passed: All Markdown inputs and YAML configs are well-formed.")
    return 0


if __name__ == "__main__":
    sys.exit(main())
