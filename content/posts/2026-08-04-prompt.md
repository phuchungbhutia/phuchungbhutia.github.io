Prompt engineering has evolved from simple text inputs into structured, command-driven workflows. By utilizing slash commands and system-level instructions, you can transform standard AI models into highly specialized tools for document processing, content creation, image restoration, and technical problem-solving.

This guide breaks down every prompt configuration covered in our workflow, showing you how to turn raw ideas into executable, highly efficient AI operations.

## 1. The Super Prompt Framework System

The foundation of command-driven AI interaction relies on a master framework. By feeding the AI a reference logic sheet at the start of a session, you enable short slash commands to trigger complex output styles, reasoning depth, and formatting guardrails instantly.

```text
You are an advanced AI assistant. From now on, you will monitor my prompts for specific slash commands to change your processing mode. When you see a command, apply the corresponding logic from this list:

## Command Logic Reference

1. Speed & Formatting
   /ELI5: Explain using simple language and no jargon.
   /TLDL: Provide a short summary of the provided text.
   /BRIEFLY: Remove all filler; get straight to the point.
   /EXEC SUMMARY: Provide a high-level overview for a CEO.
   /CHECKLIST: Convert your answer into actionable steps.
   /FORMAT AS [Type]: Output only in the specified format like Table, Markdown, or JSON.
   /ONELINER: Answer in exactly one sentence.
   /NO INTRO: Start the answer immediately without greetings.

2. Persona & Tone
   /ACT AS [Role]: Adopt the mindset and expertise of the specified role.
   /TONE [Mood]: Adjust the output to the specified mood.
   /AUDIENCE [Target]: Tailor the complexity for the specified group.
   /JARGON: Use professional and industry-specific language.
   /DEV MODE: Use a clean and code-heavy style.
   /PM MODE: Focus on timelines, risks, and resource planning.
   /GHOST: Write to sound naturally human, avoiding generic AI rhythm.
   /REWRITE AS [Style]: Change the style or genre completely.

3. Deep Logic & Reasoning
   /STEP-BY-STEP: Show full reasoning before the final answer.
   /CHAIN OF THOUGHT: Connect each idea logically.
   /FIRST PRINCIPLES: Break the problem down to its fundamental basics.
   /DELIBERATE THINKING: Process the request deeply before answering.
   /NO AUTOPILOT: Avoid generic or lazy responses.
   /REFLECTIVE MODE: Self-check the answer before outputting.
   /SYSTEMATIC BIAS CHECK: Scan the response for hidden bias.
   /EVAL SELF: Grade your own answer before showing it to me.

4. Analysis & Strategy
   /SWOT: List strengths, weaknesses, opportunities, and threats.
   /COMPARE: Provide a side-by-side breakdown of options.
   /MULTI-PERSPECTIVE: Show viewpoints from economic, social, and ethical angles.
   /PARALLEL LENSES: Apply different theories to one issue.
   /PITFALLS: Highlight what could go wrong and how to avoid it.
   /METRICS MODE: Include KPIs and measurable results.
   /CONTEXT STACK: Keep all previous context active.

5. Advanced Control
   /GUARDRAIL [Rule]: Follow the specified strict limit.
   /SCHEMA: Build a structured outline or data model.
   /DEEPDIVE: Provide extreme detail with nothing left out.
   /EDGECASES: Surface rare or overlooked scenarios.
   /BESTPRACTICE: Use only industry-standard recommendations.
   /BEGIN WITH [Text] / END WITH [Text]: Start and end with specific phrases.

## Execution
Apply these commands whenever they appear at the start of my prompt. Acknowledge this setup with a single sentence.

```

## 2. Converting Scanned PDFs into Clean Text

Raw OCR data from scanned documents often contains noise like incorrect line breaks, garbled characters (e.g., `1/I`), and broken tables. Combining persona settings, strict output controls, and layout commands forces the AI to output clean, structured Markdown ready for documentation pipelines.

```text
/ACT AS: Document Architect /NO INTRO /NO AUTOPILOT /GUARDRAIL: Retain original document hierarchy and remove all OCR artifacts like "1/I" or random symbols.

**TASK:** Convert the provided scanned PDF content into a clean Markdown (MD) format.

**LOGIC TO APPLY:**
* /STEP-BY-STEP: Analyze the text for structural elements like headers, footers, and page numbers.
* /SCHEMA: Organize the output using proper H1, H2, and H3 tags.
* /BESTPRACTICE: Use standard Markdown syntax for tables and bold text.
* /FORMAT AS: Markdown (.md) code block.

**CONTENT:**
[PASTE YOUR OCR TEXT OR ATTACH FILE HERE]

```

## 3. Real-World Super Prompt Applications

Once the framework is active, you can chain commands together for specialized tasks ranging from technical debugging to executive strategy.

### Specialized Use Case Workflows

* **Document Extraction:** Uses structural constraints to clean OCR output while preserving tables and headings.
* **Financial Strategy:** Combines executive personas with risk modeling to deliver high-level strategic analyses.
* **Technical Debugging:** Focuses output on pure code execution, edge-case coverage, and structural logic without conversational fluff.
* **Executive Summaries:** Strips out filler to deliver actionable checklists and immediate takeaway metrics for management.
* **Philosophical & Complex Logic:** Forces the model into first-principles reasoning while self-evaluating the depth of the argument.

### Prompt Templates

```text
## Document Conversion
/ACT AS Document Specialist /NO INTRO /GUARDRAIL Preserve original formatting and tables.
Extract all text from the attached scanned PDF. 
/FORMAT AS Markdown code block. 
/BESTPRACTICE Ensure clean headings and lists.

## Financial Analysis
/ACT AS Financial Analyst /PM MODE /NO INTRO.
Analyze this investment portfolio performance. 
/SWOT
/METRICS MODE include CAGR and Sharpe Ratio.
/PITFALLS highlight market risks.

## Technical Troubleshooting
/DEV MODE /STEP-BY-STEP /NO INTRO.
Debug this Linux shell script for rsync backups.
/EDGECASES check for disk space errors and permission issues.
/FORMAT AS clean code block with comments.

## Executive Briefing
/EXEC SUMMARY /BRIEFLY /TONE Professional.
Review the attached project report for the SmartScan application.
/CHECKLIST provide five immediate launch tasks.
/ONELINER summarize the primary risk.

## Complex Problem Solving
/FIRST PRINCIPLES /DELIBERATE THINKING /NO INTRO.
Explain the impact of Arthur Schopenhauer's concept of Will on modern digital consumption.
/MULTI PERSPECTIVE consider psychological and economic angles.
/EVAL SELF grade the depth of the philosophical connection.

```

## 4. Designing High-Impact GitHub READMEs

A great README needs immediate structure, clear usage instructions, and zero conversational text before the code blocks. Using `/SCHEMA` alongside `/BESTPRACTICE` guarantees a clean repository landing page.

```text
/ACT AS Open Source Developer /NO INTRO /GUARDRAIL Use clean formatting.
Create a high engagement GitHub README for a document utility project.
/SCHEMA Include project title, description, key features, installation steps, and usage examples.
/BESTPRACTICE Use modern Markdown layout with a clear structure.
/CHECKLIST Provide steps for contributors to submit pull requests.
/FORMAT AS Markdown code block.

```

## 5. Long-Form Narrative and Book Architectures

Generating large-scale content like a full book requires enforcing strict structural frameworks first, followed by character deep dives and voice control.

```text
/ACT AS Author /NO INTRO /GUARDRAIL Maintain consistent tone and character arcs.

**TASK:** Generate a comprehensive outline and the first chapter for a complete book.

**LOGIC TO APPLY:**
* /SCHEMA: Create a detailed table of contents with plot points for twenty chapters.
* /DEEPDIVE: Elaborate on world building and character backstories.
* /CHAIN OF THOUGHT: Ensure every plot development follows logical cause and effect.
* /BESTPRACTICE: Use industry standard narrative structures like the Hero's Journey.

**BOOK DETAILS:**
[INSERT GENRE AND CORE IDEA HERE]

**EXECUTION:**
1. Start with the /SCHEMA for the full book.
2. Follow with a /DEEPDIVE into the primary characters.
3. Write Chapter One in /GHOST style to ensure a natural human narrative voice.

```

## 6. Historical Photo Restoration & Image Prompts

For generative image models or restoration pipelines, prompts must explicitly define how to handle noise, missing details, historical accuracy, and structural integrity.

```text
/ACT AS: Senior Photo Restoration Specialist /NO INTRO /GUARDRAIL: Retain original subject likeness and period accuracy. Do not over-smooth.

**TASK:** Generate a high-resolution, photorealistic digital restoration based on the provided worn-out black and white image description.

**CONTENT:** A detailed description of the subject, setting, and estimated era of the original photograph (e.g., "A 1920s portrait of a grandmother in lace, sitting on a worn armchair.").

**LOGIC TO APPLY:**
* /DEEPDIVE: Analyze the description for subtle details to fill missing elements.
* /STEP-BY-STEP: Detail how to identify and repair tears, scratches, and water damage, followed by enhancing contrast and resolution.
* /BESTPRACTICE: Ensure accurate historical details in clothing and environment for the specified era.
* /REFLECTIVE MODE: Verify that the restored image looks authentic to its time period, not like a modern photo.
* /FORMAT AS: Restored high-resolution photograph description.

```
