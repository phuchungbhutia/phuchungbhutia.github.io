# 20 CMD Commands Every Windows Power User Should Know

Open Command Prompt as Administrator (search "cmd" in the Start menu, right-click, and select "Run as administrator") to unlock the full potential of these commands. Many of them require elevated privileges to function correctly.

## File and Folder Management

### 1. Robocopy — Mirror Entire Directory Trees

`Robocopy` (Robust File Copy) is a massive upgrade over the standard `copy` or `xcopy` commands. It handles interruptions, retries failed transfers, and can mirror an entire folder structure.

```cmd
robocopy C:\Source D:\Backup /MIR /R:3 /W:5
```

- `/MIR` mirrors the source to the destination, including deletions.
- `/R:3` retries failed copies three times.
- `/W:5` waits five seconds between retries.

This is ideal for automated backups and large file migrations where standard copy operations would fail silently.

### 2. Subst — Assign a Drive Letter to Any Folder

Tired of navigating deep folder paths? `Subst` maps a folder to a virtual drive letter.

```cmd
subst Z: C:\Users\YourName\Documents\Projects\DeepFolder
```

Now `Z:\` opens that folder instantly. To remove the mapping:

```cmd
subst Z: /D
```

The mapping resets after a reboot unless you place the command in a startup script.

### 3. Attrib — Hide and Unhide Files and Folders

`Attrib` modifies file attributes such as hidden, read-only, and system flags.

```cmd
attrib +h +s C:\SecretFolder
```

- `+h` sets the hidden attribute.
- `+s` marks it as a system file, making it invisible even when "Show hidden files" is enabled in File Explorer.

To reverse:

```cmd
attrib -h -s C:\SecretFolder
```

### 4. Cipher — Encrypt Folders and Wipe Free Space

`Cipher` leverages the built-in Encrypting File System (EFS) on NTFS volumes.

```cmd
cipher /E C:\SensitiveData
```

To decrypt:

```cmd
cipher /D C:\SensitiveData
```

A lesser-known use is securely wiping free space on a drive so deleted files cannot be recovered:

```cmd
cipher /W:C
```

This overwrites all unallocated space on the C: drive with zeros, then ones, then random data.

### 5. Mklink — Create Symbolic Links Across Drives

`Mklink` creates symbolic links, hard links, and directory junctions. This is useful for redirecting large folders to a secondary drive without breaking application paths.

```cmd
mklink /D C:\Games D:\ExternalSSD\Games
```

- `/D` creates a directory symbolic link.
- `/J` creates a junction (does not require admin for local targets).
- `/H` creates a hard link to a file.

### 6. Del — Clean Temporary Files and Reclaim Space

Use `Del` with wildcards to purge temporary files that accumulate over time.

```cmd
del /q /f /s %TEMP%\*
```

- `/q` suppresses confirmation prompts.
- `/f` forces deletion of read-only files.
- `/s` includes all subdirectories.

Run this periodically to recover disk space without third-party tools.

## Network and Connectivity

### 7. Netsh Wlan — View Saved Wi-Fi Passwords

`Netsh` is a Swiss army knife for network configuration. One of its most practical uses is retrieving a Wi-Fi password you have forgotten.

```cmd
netsh wlan show profiles
netsh wlan show profile name="YourNetworkName" key=clear
```

Look for the "Key Content" field under Security Settings. This only works for networks your computer has previously connected to.

### 8. Ipconfig — Fix Dropped Connections

When your internet drops or DNS resolution fails, a three-step `Ipconfig` sequence often resolves it:

```cmd
ipconfig /release
ipconfig /renew
ipconfig /flushdns
```

- `/release` drops your current IP lease.
- `/renew` requests a new one from the DHCP server.
- `/flushdns` clears the local DNS resolver cache, which can fix stale or poisoned entries.

### 9. Netstat — Monitor Active Connections and Ports

`Netstat` displays all active TCP and UDP connections, listening ports, and the processes behind them.

```cmd
netstat -ano
```

- `-a` shows all connections and listening ports.
- `-n` displays addresses and port numbers numerically.
- `-o` includes the owning process ID (PID).

Cross-reference the PID with Task Manager or `tasklist` to identify which application is using a specific port.

## System Information and Repair

### 10. Systeminfo — Full Hardware and OS Report

`Systeminfo` outputs a comprehensive snapshot of your machine: OS version, install date, BIOS, RAM, network adapters, and hotfixes.

```cmd
systeminfo
```

For a cleaner output you can filter specific fields:

```cmd
systeminfo | findstr /C:"OS Name" /C:"Total Physical Memory"
```

### 11. Tasklist and Taskkill — Find and Terminate Processes

`Tasklist` shows every running process with its PID, memory usage, and session.

```cmd
tasklist
```

Once you identify a misbehaving process, terminate it with `Taskkill`:

```cmd
taskkill /PID 1234 /F
```

- `/PID` targets a specific process ID.
- `/F` forces termination.
- You can also use `/IM processname.exe` to kill by name.

### 12. DISM and SFC — Repair Corrupted System Files

When Windows crashes, updates fail, or system files go missing, run these two commands in order.

```cmd
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

- `DISM` repairs the Windows component store using Windows Update as a source.
- `SFC` (System File Checker) scans all protected system files and replaces corrupted versions with cached copies.

Always run DISM first, then SFC. The entire process can take 15 to 30 minutes.

### 13. Whoami — Check Your Account and Permissions

`Whoami` confirms the active user context and can enumerate group memberships and privileges.

```cmd
whoami /all
```

This is essential when troubleshooting permission errors or verifying that you are running under the expected account after a `runas` switch.

## Productivity and Navigation

### 14. Clip — Pipe Command Output to the Clipboard

`Clip` takes any command output and places it on your Windows clipboard, ready to paste into any application.

```cmd
systeminfo | clip
dir C:\ | clip
```

After running either command, press Ctrl+V in Notepad, Word, or an email to paste the output directly.

### 15. Doskey — Command History and Macros

`Doskey` recalls previous commands and lets you define shortcuts for long commands you type repeatedly.

```cmd
doskey /history
doskey gs=git status
doskey ll=dir /b
```

After defining a macro, typing `gs` executes `git status`. Macros persist only for the current session unless added to your AutoRun registry key.

### 16. Start — Launch Apps, Websites, and Folders

The `Start` command opens files, programs, URLs, and directories from the command line.

```cmd
start https://example.com
start notepad
start C:\Users\YourName\Documents
```

This is particularly useful in batch scripts that need to open a browser window or a specific folder after completing a task.

### 17. Where — Locate the Exact Path of a File or Program

`Where` searches your PATH and returns the full location of an executable or file.

```cmd
where python
where notepad.exe
```

If multiple versions of a program exist on your system, `Where` lists all of them in order of PATH priority, which helps diagnose version conflicts.

### 18. Jump Between File Explorer and Command Prompt

This is a navigation technique rather than a single command, but it saves significant time.

- **From Explorer to CMD:** Type `cmd` in the File Explorer address bar and press Enter. A Command Prompt opens in that exact directory.
- **From CMD to Explorer:** Type `start .` to open the current directory in File Explorer.

```cmd
start .
```

## Advanced Tricks

### 19. Alternate Data Streams — Hide Text Inside a Normal File

NTFS supports Alternate Data Streams (ADS), which let you attach hidden data to an existing file without changing its visible size or content.

```cmd
echo This is a secret message > normalfile.txt:secret.txt
```

The file `normalfile.txt` appears unchanged in Explorer. To read the hidden stream:

```cmd
notepad normalfile.txt:secret.txt
```

To detect ADS on a file:

```cmd
dir /R normalfile.txt
```

ADS is a legitimate NTFS feature used by browsers to flag downloaded files, but it can also be abused to conceal data.

### 20. Color, Title, and Prompt — Customize Your CMD Window

Personalize the look and feel of your Command Prompt session.

```cmd
color 0A
title My Admin Console
prompt $P$G$S
```

- `color 0A` sets a black background with green text. The first digit is the background, the second is the foreground. Run `color /?` for the full palette.
- `title` changes the window title bar text.
- `prompt` modifies the input cursor. `$P$G` is the default path and greater-than sign. `$S` adds a space.
